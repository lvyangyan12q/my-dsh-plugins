### 发现并修复的验收缺陷

首次 2026-11-05 真实运行在写盘时失败：

```
paper-reader: digest does not match the day contract:
  digest.items[7].summary must be { original, translation }
paper-reader: the day digest was not written        (exit 1)
```

原因：Kimi 条目没有 dek，`toDigestItem` 写出了 `summary: null`，而 v2 契约把 `summary` 当作可选 key、存在时必须是对象。整个当天的文件因此被拒写。修复：无摘要时省略 `summary` key（`src/pipeline/run.js`），并新增回归测试 `test/pipeline.test.mjs`「an item with no summary omits the key instead of writing null」。修复后重跑成功；失败那次的 run 记录与「不覆盖上一份」行为同时被验证。
