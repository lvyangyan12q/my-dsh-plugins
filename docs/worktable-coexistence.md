# 两个工作台插件并存

自研 personal-workbench 与开源 dsh-worktable 可以同时安装，通过独立入口比较。

## 修复

DSH 原生 sidebar.footer.action 容器为 flex 横排。两个插件各自声明全宽时发生收缩：256px 容器被分成约 117px 和 139px，造成标题竖排、应用名截断。

自研插件的兼容样式仅在自己的菜单标记存在时，将该容器改为纵向排列；两个菜单均占完整宽度。自研入口标注“自研平台”，开源入口标注“Worktable”。原生 DSH 源码和开源插件源码未修改。

## 对比路径

- 自研：工作台（自研平台） → 应用配方 → 页面模板、模块内容、数据和角色配置。
- 开源：工作台 · Worktable → 添加项目 → 布局预设；保留其原始配色及交互。
- DSH 原生工作区和会话菜单保持原有入口。

## 验证

2026-10-03，使用已构建的插件在 3082 浏览器验证：两菜单宽度均为 256px，纵向间隔 8px；侧栏收起、展开正常，开源布局选择器显示完整。三个本地插件构建成功，220 项测试通过。四个 Agent 管理改动文件和四个开源源文件/构建入口的 SHA-256 与修复前一致。

3080 与 3082 使用同一 profile 的插件目录链接，刷新即可读取新的客户端构建。本次浏览器验证在 3082 完成；3080 此前被浏览器访问策略阻止，未宣称其 UI 验证通过。未重启正式宿主。

兼容选择器采用原生 CSS module 的 footerActions 局部类名；后续宿主若重命名该容器，需要复核布局。
