# 工作台画布实施记录

本轮基线为 `0dbefc3`，沿用用户批准的 8 张本地工单。当前实现分支为 `codex/application-platform`，交互按 A 模块内配置推进。此记录是阶段证据，不代替全部工单验收。

## 已实现并验证

应用创建从布局缩略图进入空模块画布。四格、双栏、纵向分别对应 4、2、3 个空模块。网站、自定义页面、DSH 对话、资源、动画及数据展示在目标模块选择；模块名称、地址、数据连接与角色在模块内配置。集中四步表单移入高级设置。原有草稿、安装应用模板和 AI 生成入口保留。

应用、页面、模块身份独立于名称；配置另一模块不会改变其他模块身份或内容。保存、只读预览、显式启用持续使用原 Host CAS 接口。编辑后预览失效，未保存或未预览不能启用。未改变原始业务记录或会话历史。

配方新增可选可信工作目录，兼容旧配方。目录来自 DSH 已注册且状态正常的工作区；预览及启用验证目录。实例首次使用时固定目录；已有实例遇到变更会明确拒绝，新实例采用新目录。已有会话不会被迁移。

浏览器在正式 3082 宿主完成：双栏创建、左模块配置 `https://example.com/`、保存、预览、显式启用、打开真实网站、刷新、恢复同一草稿及模块身份。网站保留单独打开入口。检查时文档宽度等于 1280px 视口，两个模块均无横向溢出。新建验收应用名为“画布网站验收”，保留作为可复查证据。

角色服务原先在根作用域依赖仅会话作用域提供的 `conversation`，改为依赖根服务 `uiConversation`，实际发送仍通过所绑定会话的原生 `conversation`。已验证考公独立学习窗口恢复角色入口与资料分析老师的原生输入区，未发送模型任务。

## 原生完整会话的未完成范围

原生 `conversation.session.header` 是 `conversation.header` 独占的子插槽。直接从角色模块再次声明会报“already declared”，导致整个角色注册回滚。临时声明和诊断日志已移除；不能用重复声明接入完整标题/轨迹导航，也不能以消息正文或输入区恢复宣称完整会话通过。

继续寻找受支持的完整原生嵌入方式，必要时提供有明确来源、可分发的原生兼容适配；不得覆盖原生菜单、绕过插槽归属或复制轨迹实现。已有会话绑定操作、工具与审批真实闭环仍需补齐。
