**Status:** in-progress

- [ ] 一个真实深度应用能提供完整页面和可嵌入模块，通过统一注册进入已有项目；无需加载旧工作台前台。
- [ ] 同实例两个视图共享已声明的工作状态；移动标签、改变窗格或重复打开不新建实例和会话。
- [ ] 跨项目及显式新建实例拥有独立状态，实例上下文不由当前全局会话、目录或窗格序号推导。
