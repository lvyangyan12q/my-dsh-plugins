# 02: 确认项目、应用与实例的关键交互原型

**What to build:** 可演示无项目原生AI入口、打开未归属实例、创建项目、显式关联实例和项目内多应用组织。

**Blocked by:** None (can start immediately)。

**Status:** in-progress

- [ ] 可演示无项目原生AI入口、打开未归属实例、创建项目、显式关联实例和项目内多应用组织。
- [ ] 重复打开恢复最近实例，新建实例与添加同实例视图区分；明确展示实例归属和共享权限。
- [ ] 完整应用页面与模块都能在原型中表达；不把原型样例、假数据或模拟执行当真实接入验收。
- [ ] 桌面及窄屏下主要控件可见、可键盘操作，保留原生菜单位置；框架高级配置不挤占日常AI流程。
- [ ] 用户实际评审原型并确认关键行为；有待修改时保留开放状态，不能由agent代替用户确认。

## Scope and evidence

依据[框架与应用接入规格](../framework-spec.md)及其中首阶段限定；真实安装用户流程为主接缝，契约测试只作辅助。记录版本、操作、结果与限制；无证据不勾选、不以提交或构建成功关单。保留用户数据、源码改动、原生DSH和历史工单状态。
