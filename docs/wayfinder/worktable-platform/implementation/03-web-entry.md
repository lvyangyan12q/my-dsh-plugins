# 03: 网页应用与未归属实例接入

**What to build:** 通过公开注册接入一个真实网页应用，可独立打开并明确标记未归属实例。

**Blocked by:** [保护本地改动并验证派生基线](01-baseline.md)、[确认项目、应用与实例的关键交互原型](02-prototype.md)。

**Status:** closed

- [x] 通过公开注册接入一个真实网页应用，可独立打开并明确标记未归属实例。
- [x] 用户可关联到一个项目且保留实例身份，不移动资料、不重建会话；同实例不能同时归属多个项目。
- [x] 同项目再次打开恢复最近实例，显式新建与增加视图区分；刷新和重新打开保留该条链的实例与入口关联。
- [x] 跨域不可读、拒绝嵌入或链接失效有明确反馈，允许可行外部打开；不承诺普通网页内部状态同步。
- [x] 普通网页不取得原生工具、凭据、文件和其他实例访问权限；缺失注册及版本不兼容不静默换应用。

## Scope and evidence

依据[框架与应用接入规格](../framework-spec.md)及其中首阶段限定；真实安装用户流程为主接缝，契约测试只作辅助。记录版本、操作、结果与限制；无证据不勾选、不以提交或构建成功关单。保留用户数据、源码改动、原生DSH和历史工单状态。

保留失败和修复过程：首包安装后目录真实 503，修正公开依赖 fiber 生命周期；审查发现迟到响应可能串实例及最近使用未更新，分别修复稳定 key/请求代次/取消/动作身份和显式 resume。真实 React 延迟回归对旧源码红、修复绿。自动审批曾因已知串位风险拦截添加视图；先修复并复审，再在真实 UI 成功执行。归属矛盾标题同时修正。
