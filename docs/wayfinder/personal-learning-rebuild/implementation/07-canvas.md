# 07: 课程脉络

**What to build:** 在学习空间里切到「脉络」，看到 `脉络.canvas` 里的概念节点和它们之间的有向关系；点击某个节点能直接打开对应的讲义或笔记。插件内不编辑画布，需要改结构时给出在 Obsidian 中打开的方式与文件路径。

**Blocked by:** 02 目录与讲义阅读

**Status:** ready-for-agent

- [ ] 渲染 JSON Canvas 的文本、文件、链接与分组节点，以及带标签的有向边。
- [ ] 点击文件节点打开对应讲义或笔记；目标不存在时给出明确提示。
- [ ] 画布文件缺失或格式非法时显示错误，不渲染半张图。
- [ ] 关系类型（先修、组成、应用）在界面上可区分。
- [ ] 插件内没有加节点或连线的编辑入口；提供「在 Obsidian 中打开」与文件路径提示。
- [ ] 脉络视图与讲义、笔记选择互不覆盖，切换回来后状态保留。
