# 01: 课堂骨架与知识库

**What to build:** 安装并启用「学习课堂」后，从侧栏打开主面板；第一次使用时选择一个本地目录作为知识文件库，然后创建一个学习空间，磁盘上出现该空间的文件夹和默认笔记；关闭再打开，学习空间还在。主面板此时呈现四区骨架（目录、讲义、笔记、对话），对话区是明确的未连接占位。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 启用后侧栏出现「学习课堂」，主面板可打开；未选知识库时显示可操作空状态而不是报错。
- [ ] 可以把一个已存在目录设为知识文件库，路径被保存，重启宿主后仍保留。
- [ ] 创建学习空间会在知识库根下建立同名文件夹（讲义、笔记、附件），并写入一个默认笔记文件。
- [ ] 拒绝不存在、不可写、或越出知识库根的路径，并说明原因。
- [ ] 主面板呈现四区骨架；对话区显示未连接占位，不伪造聊天。
- [ ] 学习空间列表与当前选择跨重启保留；插件状态是新的存储身份，不读写旧个人学习域。
