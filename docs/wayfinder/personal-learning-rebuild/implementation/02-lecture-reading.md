# 02: 目录与讲义阅读

**What to build:** 打开学习空间后，左侧目录列出该空间 `讲义` 文件夹里的课程文件；点击一个 Markdown 讲义，右侧以排好版的阅读视图呈现标题、列表、表格、代码和引用。关掉再回来，仍停在上一节讲义。

**Blocked by:** 01 课堂骨架与知识库

**Status:** ready-for-agent

- [ ] 目录由 `讲义` 目录下的文件推导，按文件名排序；文件头 `order` 与 `title` 可覆盖顺序和显示名。
- [ ] 点击讲义渲染为可读排版；无法识别的结构降级为纯文本而不是空白。
- [ ] 当前讲义选择被保存，重新打开学习空间回到该讲义。
- [ ] 讲义被外部删除或改名时提示，并回到可操作状态。
- [ ] 空间里还没有讲义时显示空状态和下一步提示。
- [ ] 讲义切换不丢失笔记区与对话区的状态。
