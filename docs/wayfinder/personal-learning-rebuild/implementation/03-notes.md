# 03: 笔记编辑与冲突

**What to build:** 课堂右侧的「我的笔记」读出知识库里的 Markdown 文件，可以直接编辑并自动保存；磁盘上能看到同样的内容。用 Obsidian 或别的编辑器改了同一个文件后，插件保存时会明确提示冲突，让我选择重新加载还是用我的覆盖。

**Blocked by:** 01 课堂骨架与知识库

**Status:** ready-for-agent

- [ ] 打开学习空间显示默认笔记内容；可以切换到 `笔记` 目录下其他 Markdown 文件。
- [ ] 编辑后自动保存，磁盘文件内容与界面一致；保存中、已保存、失败三态可见。
- [ ] 外部修改同一文件后再保存被拒绝，界面给出「重新加载」与「用我的覆盖」两个明确选择，不静默覆盖。
- [ ] 保存失败（权限、目录被删）时保留编辑内容并说明原因。
- [ ] 老师侧工具无法写入 `笔记` 目录；拒绝时不破坏原文件。
- [ ] 插件只保存导航状态，笔记正文始终是文件本身。
