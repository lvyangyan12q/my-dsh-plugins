# 04: 双链与选段批注

**What to build:** 笔记与讲义里的 `[[...]]` 双链在课堂内可点击跳转；在讲义中选中一段文字，可以一键插入一条带原文和来源的批注到笔记末尾，并停在「我的想法」后面。

**Blocked by:** 02 目录与讲义阅读、03 笔记编辑与冲突

**Status:** ready-for-agent

- [ ] `[[讲义/某课]]` 与 `[[讲义/某课#^块id]]` 在课堂内跳转到对应讲义与位置。
- [ ] 解析不到目标时显示未解析状态，不猜测、不改写原文。
- [ ] 选中讲义文字触发「引用到笔记」，在笔记末尾插入 Obsidian 兼容的批注块，包含原文、来源链接与空的想法位置。
- [ ] 插入不覆盖已有内容；插入后焦点落在想法位置。
- [ ] 生成的 Markdown 在 Obsidian 中仍可正常解析（双链与 callout 语法有效）。
- [ ] 同一段文字重复插入时按约定追加，不静默去重丢失记录。
