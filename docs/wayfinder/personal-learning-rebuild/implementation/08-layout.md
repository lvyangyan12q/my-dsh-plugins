# 08: 布局拖拽与记忆

**What to build:** 目录、笔记、对话三栏都能收起和恢复，栏与栏之间的分隔条可以拖动改变宽度；关掉学习空间再回来，布局和上次一样。窄窗口下不横向滚动，一次显示一个区。

**Blocked by:** 02 目录与讲义阅读、03 笔记编辑与冲突

**Status:** ready-for-agent

- [ ] 目录、笔记、对话各自可收起，收起后出现明确的恢复入口。
- [ ] 拖动分隔条改变相邻栏宽度；讲义有最小宽度，不会被挤到不可读。
- [ ] 重新打开同一学习空间恢复宽度与可见性；不同空间互不影响。
- [ ] 窄屏下改为分区切换而不是横向滚动，默认显示讲义。
- [ ] 键盘可以完成收起、恢复和切换分区。
- [ ] 收起或调整布局不触发模型请求，也不打断正在进行的会话。
