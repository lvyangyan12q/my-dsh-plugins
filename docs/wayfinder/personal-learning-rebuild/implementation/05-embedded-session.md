# 05: 内嵌老师会话

**What to build:** 课堂右侧是真实 DSH 会话：可以提问、看到流式输出与工具结果、点原生停止、回答问题与审批，全部留在课堂里不跳转。收起对话栏不会中断正在进行的回合，展开后接着看。

**Blocked by:** 01 课堂骨架与知识库

**Status:** ready-for-agent

- [ ] 首次提问或显式打开时创建并绑定一个标准预设会话，`sessionId` 保存到插件状态。
- [ ] 课堂内可发送消息，看到流式输出与工具呈现，不是本地假回复。
- [ ] 停止按钮可用，且只在用户操作时触发，不因收起或切课自动取消。
- [ ] 收起对话栏后回合继续；展开仍在进行或已完成的真实状态。
- [ ] 页面上始终只有一个可编辑输入框，不出现第二个 composer。
- [ ] 切换学习空间不串会话；会话不可用时显示真实错误与重试，不降级为假聊天。
- [ ] 离开课堂只释放客户端引用，会话历史与 Host 状态保留。
