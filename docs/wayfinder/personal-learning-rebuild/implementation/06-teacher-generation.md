# 06: 老师生成讲义与实验

**What to build:** 在课堂里请老师为某个知识点生成一节讲义或一个动态实验，生成成功后 `讲义` 目录里出现真实文件，并可以立即阅读。动态实验在隔离画布里运行，读不到笔记、凭据或宿主数据。

**Blocked by:** 02 目录与讲义阅读、05 内嵌老师会话

**Status:** ready-for-agent

- [ ] 老师通过插件工具写入讲义 Markdown 后，目录与阅读视图立即可见，文件真实存在于知识库。
- [ ] 非绑定会话或跨学习空间的写入被拒绝，原文件不受影响。
- [ ] 生成失败或取消时保持原讲义与笔记不变，不产生半成品文件。
- [ ] 动态实验以隔离 iframe 运行：无网络、无父页面访问、无宿主文件与凭据读取。
- [ ] 实验无法渲染（文件缺失、脚本错误）时显示可理解错误，并仍可读讲义。
- [ ] 老师工具明确不能改写 `笔记` 目录。
- [ ] 老师的教学技能与工具在缺少时给出可操作提示，不用假内容代替。
