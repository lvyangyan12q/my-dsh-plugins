# 学习课堂

从零重建的个人学习插件。取代已删除的旧「个人学习」实现，不读取旧存储域 `personal_learning`，不迁移旧数据，不兼容旧实验台协议。

## Problem Statement

我在 DSH 里学抽象知识时，需要同时做四件事：看讲义、随手记自己的理解、遇到不懂的地方直接问老师、以及知道这一课在整个知识脉络里的位置。现在这四件事分散在不同地方——讲义在网页里、笔记在 Obsidian 里、对话要跳到原生会话、知识关系只有一张图，来回切换会打断理解，也让我很难接上上一次学到哪。

我真正的困难不是"没有交互课件"，而是：**没有一个连续的学习空间，让我看、写、问、走脉络都不离开当前这一课。**

同时我需要内容长期可读、可带走、可被别的工具理解。我不希望课程和笔记被锁在某个插件的私有数据库里。

## Solution

一个独立 DSH 插件「学习课堂」，作为侧栏入口和主面板课堂：

- 打开一个学习空间，直接进入四区课堂：**课程目录 / 讲义 / 我的笔记 / 老师对话**。分隔条可拖拽，目录、笔记、对话可收起并恢复。
- **讲义**以 Markdown 阅读为主；复杂知识点可生成**动态实验**（独立 HTML），在隔离画布里打开。
- **我的笔记**是真实 Markdown 文件，支持 Obsidian 兼容双链；选中讲义原文可生成带出处的批注。
- **老师对话**是真实 DSH 会话，内嵌在课堂里，不跳转；保留原生停止、提问和审批。
- **课程脉络**用 Canvas（JSON Canvas 1.0）呈现，可查看、可点击进入讲义或笔记；编辑交给 Obsidian。
- 所有内容落在**知识文件库**（一个本地目录）里，Obsidian 可直接打开同一批文件。

## User Stories

1. 作为学习者，我希望从 DSH 侧栏直接打开学习课堂，以便不离开日常环境就能学习。
2. 作为学习者，我希望首次使用时只选一个知识文件库目录就能开始，以便不用先理解插件内部结构。
3. 作为学习者，我希望用一句话描述学习目标就创建学习空间，以便尽快进入学习而不是配置。
4. 作为学习者，我希望学习空间在我的知识文件库里是一个普通文件夹，以便随时用文件管理器或 Obsidian 打开。
5. 作为学习者，我希望看到这一课的目录（章、节、讲义、实验），以便知道课程范围和当前位置。
6. 作为学习者，我希望目录可以收起，以便把空间让给讲义。
7. 作为学习者，我希望目录按我在文件里写的顺序或标题显示，以便 Obsidian 里的组织直接生效。
8. 作为学习者，我希望讲义默认是排好版的 Markdown，以便长时间阅读不疲劳。
9. 作为学习者，我希望讲义里的公式、代码和表格正常显示，以便不用切换工具核对内容。
10. 作为学习者，我希望遇到抽象概念时能打开一个可操作的动态实验，以便建立直觉。
11. 作为学习者，我希望动态实验不会读我的笔记、凭据或宿主数据，以便放心运行生成内容。
12. 作为学习者，我希望动态实验可以随时关闭回到讲义，以便不丢失阅读位置。
13. 作为学习者，我希望讲义和笔记左右并排，以便边读边写。
14. 作为学习者，我希望拖动分隔条调整讲义和笔记宽度，以便按当前任务分配空间。
15. 作为学习者，我希望笔记栏可以收起和恢复，以便专心阅读时界面干净。
16. 作为学习者，我希望我的笔记是普通 Markdown 文件，以便用 Obsidian、其他编辑器或 Git 管理。
17. 作为学习者，我希望在讲义中选中一段文字后能一键生成带出处引用的批注，以便笔记里保留"我当时在读什么"。
18. 作为学习者，我希望批注里的来源链接能点回讲义对应位置，以便复习时回到原文。
19. 作为学习者，我希望用 `[[讲义/某课]]` 这样的双链引用其他讲义或笔记，以便内容之间可以连起来。
20. 作为学习者，我希望双链在插件内可点击跳转，以便不离开课堂。
21. 作为学习者，我希望笔记自动保存，同时能看到"已保存/保存失败"，以便不用担心丢字。
22. 作为学习者，我希望外部编辑器改过同一个笔记时被明确提示，以便选择保留哪一份而不静默覆盖。
23. 作为学习者，我希望老师对话就在课堂右侧，以便问问题不用切页面。
24. 作为学习者，我希望老师看到的是当前讲义、当前选段和我刚写的笔记，以便少解释一遍背景。
25. 作为学习者，我希望老师对话是真实会话，能停止、能回答提问、能审批，以便不面对一个"看起来像聊天"的假界面。
26. 作为学习者，我希望收起对话栏时对话不中断，重新展开还在进行，以便临时专心阅读。
27. 作为学习者，我希望切换课程时不会串掉另一门课的对话或笔记，以便多个主题互不影响。
28. 作为学习者，我希望离开课堂再回来时恢复上次的课程、笔记、滚动位置和栏宽，以便接着学。
29. 作为学习者，我希望重启 DSH 后学习空间仍然存在，以便内容不丢。
30. 作为学习者，我希望在知识脉络里看到概念节点和它们的关系，以便理解知识结构而不是只记单点。
31. 作为学习者，我希望点击脉络里的节点能打开对应讲义或笔记，以便从"知道有关系"走到"开始学"。
32. 作为学习者，我希望脉络关系类型（先修/组成/应用）有明确含义，以便知道连线的意义。
33. 作为学习者，我希望脉络里没有对应课程时能明确看到"还没有内容"，以便知道该生成什么。
34. 作为学习者，我希望请求老师为某个概念生成讲义或实验，以便补齐缺失内容。
35. 作为学习者，我希望只有生成成功、文件真实写入后才算有内容，以便不会看到假的"已完成"。
36. 作为学习者，我希望生成失败时原来的讲义和笔记完好，以便一次失败不毁掉已有学习材料。
37. 作为学习者，我希望老师生成的内容明确写入知识文件库，以便我可以在 Obsidian 里修改它。
38. 作为学习者，我希望老师不悄悄改写我的个人笔记，以便我的理解记录保持是我的。
39. 作为学习者，我希望插件不读旧版个人学习插件的数据，以便新版本从干净状态开始。
40. 作为学习者，我希望知识文件库不可访问时看到明确原因和修复入口，以便知道是路径问题还是权限问题。
41. 作为学习者，我希望窄屏下四区改成按需切换而不是横向滚动，以便在分屏里也能学。
42. 作为学习者，我希望用键盘完成折叠、切换课程、在笔记里写和保存，以便不依赖鼠标。
43. 作为学习者，我希望看到当前学习空间的目标，以便判断这节课是否还服务于我的目标。
44. 作为学习者，我希望老师能基于已有笔记和讲义判断我卡在哪，以便下一步不是从零开始。
45. 作为学习者，我希望一次学习结束时留下可追溯的小结和下次位置，以便隔几天回来能接上。

## Implementation Decisions

### 产品身份与边界

- 新插件 `@deepseek-ai/dsh-learning-classroom`，侧栏标签「学习课堂」，主面板 key 与侧栏 panellist id 同名（沿用宿主公开注册方式）。
- 新的存储域 `learning_classroom`（版本 1）。**禁止**读取或写入旧域 `personal_learning`。旧插件源码与发行包已删除，不复用。
- 插件自己的状态只保存"导航与绑定"：学习空间、会话 id、文件选择、栏宽与可见性、滚动锚点。**讲义正文、笔记正文、脉络内容不进存储域**，它们是知识文件库里的文件。
- 知识文件库根目录由用户显式选择一次，必须是一个已存在的目录；保存其绝对路径。所有文件读写都限制在该根内。

### 知识文件库布局

每个学习空间对应根目录下一个文件夹，由插件创建：

```text
<知识库根>/
└─ <学习空间名称>/
   ├─ 讲义/        # 01-xxx.md、02-xxx.html（HTML 即动态实验）
   ├─ 笔记/        # 默认一个笔记文件；允许多个
   ├─ 脉络.canvas  # JSON Canvas 1.0
   └─ 附件/
```

- 课程目录由**文件系统推导**：`讲义/` 下的 `.md` 与 `.html` 按文件名排序；文件头 frontmatter 的 `order` 和 `title` 可覆盖排序与显示名。目录不另存一份清单，避免双份真相。
- 笔记默认文件名为 `笔记/我的笔记.md`；用户可以新增其他 `.md`，笔记区提供切换。插件不假设只有一个笔记。
- 生成内容与个人笔记分离：老师只能写 `讲义/`、`脉络.canvas`、`附件/`，不能覆盖 `笔记/`。

### 宿主文件接口（Host 侧）

浏览器侧的 `workspaceFiles` 只读，因此由插件 Host 服务提供受控读写：

- `vault.status()`：根目录存在性、可读可写、是否为已登记工作区。
- `vault.list(spaceId)`：返回目录树（讲义节点、笔记节点、canvas 是否存在）。
- `vault.read(path)`：有大小上限的文本读取，返回 `{content, version}`。
- `vault.write(path, content, expectedVersion?)`：原子写入；版本不符返回冲突错误，不静默覆盖。
- `vault.writeBinary`（仅实验 HTML 与附件）：同样受路径与版本约束。
- 路径规则：必须是知识库根内的相对路径；拒绝 `..`、绝对路径、盘符、UNC、符号链接越界。所有路径在 Host 侧重新校验，不信任浏览器传值。
- `version` 用内容哈希，保证外部编辑也能被识别。
- 同一路径的写入串行化，避免自动保存与生成互相踩踏。

### HTTP 应用接口

单一入口 `/api/learning-classroom`，与旧插件不同路径，避免任何残留冲突。

- `GET` 返回学习空间列表与当前选择。
- `POST` 命令式，必须带 `action`，未知字段与未知 action 一律拒绝。
- 关键命令：`space-create`、`space-open`、`space-rename`、`vault-choose`、`lecture-list`、`lecture-read`、`note-list`、`note-read`、`note-save`、`note-create`、`canvas-read`、`layout-save`、`session-open`。
- `note-save` 必须携带读取时的 `version`；冲突返回 409 风格业务错误，前端展示"重新加载 / 保留我的"。
- 所有命令在此边界串行化；写入成功后才返回成功。

### 会话归属与内嵌

- 每个学习空间绑定**一个** DSH Session（标准预设），在首次提问或显式"打开老师会话"时创建；`sessionId` 存于插件状态。
- 客户端内嵌走宿主当前公开组合：`sessions.retain(id, {source})` 取得自有引用 → 在独立 main 的 session 子 seat 上由 `SessionProvider` 包裹 → 渲染 `conversation.content` 的 embedded 变体。
- 不导入私有 Chat 组件，不模拟聊天，不调用会跳转原生页面的 `openSession`。
- 卸载或切换课程时**释放引用**，但不取消 Host 回合：Stop 只能由用户显式操作。切回时重新 `retain`，不复用已释放引用。
- 同一空间不允许出现两个可编辑 composer；四区内只渲染一处对话。
- 会话不可用时显示真实错误与"重试"，不退回假的本地回复。

### 老师能力（Skill 与工具）

- 内置技能（如 `learning-classroom-teach`）规定：先确认目标与已有基础；一次一个概念；来源与解释分开；用变式题检查迁移；不把看过或答对一次当成掌握。
- Agent 工具：
  - `learning_lecture_write`：写讲义 Markdown（标题、正文、顺序），只能写绑定空间。
  - `learning_experiment_write`：写动态实验 HTML。
  - `learning_canvas_write`：写 JSON Canvas 节点与关系，校验引用与先修环。
  - 读取工具：列目录、读讲义、读笔记（只读）。
- 工具只接受**绑定会话**调用；拒绝跨空间写入。工具成功回执才代表文件已写入。
- 老师**不写** `笔记/`；若想建议笔记，只在对话中给出文本，由学习者自己粘贴或确认。

### 课堂界面

四区结构，顺序固定：课程目录、讲义、笔记、老师对话。

```text
┌──────────────────────────────────────────────────────────┐
│ 学习空间 / 当前课程            课堂 · 脉络   页面操作    │
├──────────┬──────────────────┬─────────────┬───────────────┤
│ 课程目录 │ 讲义 / 动态实验  │ 我的笔记    │ 老师对话      │
│ 可收起   │ 主内容           │ 可收起      │ 可收起        │
└──────────┴──────────────────┴─────────────┴───────────────┘
```

- 目录、笔记、对话三栏各自可收起，收起后出现固定恢复按钮；讲义始终存在。
- 相邻栏之间有拖拽分隔条，宽度持久化；讲义有最小宽度，避免被挤没。
- 窄屏（阈值由实现确定）不横向滚动：一次只显示一个区，用标签或分段控件切换，讲义优先。
- 布局状态按学习空间保存；不同空间互不影响。
- 「课堂 / 脉络」在主内容区切换，不额外增加第五栏。
- 不提供源码查看器：需要看原始文件时用宿主既有文件打开入口，或提示在 Obsidian 中打开。

### 讲义渲染

- Markdown 渲染为只读排版（标题、列表、表格、代码、引用、公式按宿主已有能力取舍）。
- 双链 `[[路径#标题]]`、`[[路径#^块id]]` 解析为站内跳转；解析不到的链接显示为未解析状态，不猜测目标。
- 动态实验用隔离 iframe 渲染：沙箱只允许脚本，CSP 禁止网络、外部资源、表单与父页面访问；高度可自适应或由讲义声明。
- 实验与讲义同属"这一课"，切换不丢阅读位置。

### 笔记编辑与批注

- 笔记区是 Markdown 文本编辑 + 预览切换；不实现富文本。
- 自动保存采用防抖 + 显式保存；保存中、已保存、失败三态可见。
- 外部修改：保存时版本冲突，展示差异提示与"重新加载 / 用我的覆盖"，不自动二选一。
- 选段批注：在讲义中选中文字 →「引用到笔记」，在笔记末尾插入 Obsidian 兼容块：

```markdown
> [!note] 批注
> 原文：<选中文字>
> 来源：[[讲义/01-缩小样本空间#^anchor-1]]
>
> 我的想法：
```

- 插入后光标落在"我的想法"后；不覆盖已有内容。
- 双链与 callout 只用 Obsidian 已支持的语法，不发明私有格式。

### 课程脉络

- 读取 `脉络.canvas`（JSON Canvas 1.0）：文本、文件、链接、分组节点与带标签的有向边。
- 在课堂内**只读**渲染：可平移缩放，点击文件节点打开对应讲义或笔记。
- 编辑不在插件内进行；提供"在 Obsidian 中打开"（可用时）与显示文件路径。
- 文件缺失或格式非法：显示可理解错误，不渲染半张图。

### 错误与状态

必须明确区分并给可操作出口：知识库未选择 / 根目录不可访问 / 学习空间为空（无讲义）/ 文件被外部删除 / 保存冲突 / 会话创建失败 / 技能或工具不可用 / 实验渲染失败。

### 不变量

- 不读旧 `personal_learning` 域，不迁移旧数据。
- 不把正文写进存储域（只存导航与绑定）。
- 不在插件内编辑 Canvas。
- 不覆盖用户笔记；老师只能写讲义、脉络、附件。
- 卸载视图不等于停止会话。

## Testing Decisions

好的测试只断言**用户可见行为与持久结果**：文件是否真的写进了知识库、冲突是否被拦住、布局与会话是否恢复、未选知识库时是否给出可操作状态。不断言私有函数调用次数、组件内部 state 或类名。

两个 seam，按优先级：

1. **宿主集成 seam（最高）**——在临时 `DSH_HOME` 安装并启动真实宿主插件，通过 HTTP 应用接口走完整流程：选知识库 → 建学习空间 → 生成讲义文件 → 读取 → 保存笔记 → 版本冲突 → 重启后恢复。这一层用真实文件系统，验证路径校验、原子写、版本冲突与持久化。参考仓库现有 `scripts/check-platform-tests.mjs`、`check-native-public-runtime.mjs` 一类的宿主检查方式。
2. **客户端渲染 seam**——jsdom + React 渲染课堂，注入假的 HTTP 与会话边界（不是假聊天运行时），断言：四区存在、收起与恢复、栏宽持久化、未选知识库的空状态、选段批注插入的 Markdown 文本、笔记冲突提示、窄屏切换。参考 `plugins/reading-statistics`、`plugins/project-notes` 的 jsdom 测试组织。

纯逻辑（路径校验、目录排序、双链解析、Canvas 校验、冲突判定）用直接单测，不另建 seam。

内嵌会话的真实性（输入/输出/工具/Stop/提问/审批）**不能**由以上自动化证明，需一次真实浏览器验收。

## Out of Scope

- 旧插件兼容、旧数据迁移、旧实验台协议、双版本并行。
- 重写 DSH 聊天、工具执行、审批或 Stop 运行时。
- 在插件内编辑 Canvas、富文本编辑器、独立源码查看器。
