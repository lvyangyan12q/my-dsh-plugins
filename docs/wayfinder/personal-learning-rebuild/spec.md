# 学习课堂：B 阅读优先

本规格是全新个人学习插件的唯一要求正文。本轮按用户选定的 B「阅读优先」原型修订第一版；已有实现是待整合基础，不因此视为满足本规格。原实现已删除，不迁移旧数据。文中区分用户明确方向、首版实施默认和真实验收门槛。

## Problem Statement

个人自学需要在同一个课堂里看讲义、写自己的理解、随时问老师，并查看知识点脉络。跳到另一页聊天或在多个工具间搬运内容会打断学习；只有漂亮课件而没有关联笔记与持续对话，也无法接上上次学习。

学习者希望日常在 DSH 使用这些能力，同时把讲义、笔记和课程脉络保存为 Obsidian 可直接使用的文件，随时能打开原始内容，不被插件私有数据格式锁住。首版应简单可用，不以完整教育平台或完整笔记软件为目标。

## Solution

提供独立的 DSH「学习课堂」，以用户明确选定的 B 阅读优先布局作为设计基线：窄课程目录、宽主内容、右侧个人笔记与老师对话。各辅助区可收起恢复，支持拖拽分栏；不必四栏始终展开。

主内容在讲义、动态实验、Canvas 课程脉络之间切换；不把整个课堂替换成画布。笔记和老师仍可保留，支持看着脉络提问。讲义优先采用 Markdown，复杂知识点才按需生成可操作页面。

知识正文位于一个显式选择的本地知识文件库；DSH 与 Obsidian 使用同一份文件，不维护同步副本。老师对话嵌入真实 DSH Session，不跳转、不模拟聊天。提问时能明确携带当前讲义、选段或笔记片段，个人笔记修改保持在学习者控制下。

首版完整体验：选择知识库 → 新建或打开学习主题 → 阅读讲义 → 写笔记 → 选段问老师或记批注 → 查看脉络 → 离开后继续。

## User Stories

1. 作为个人学习者，我希望从 DSH 侧栏打开学习课堂，以便在日常环境中学习。
2. 作为个人学习者，我希望选择本地知识文件库，以便文件保存位置由我决定。
3. 作为个人学习者，我希望在知识库中创建学习主题并填写目标，以便课程有明确方向。
4. 作为个人学习者，我希望打开已有主题文件，以便不必重新生成材料。
5. 作为个人学习者，我希望空课堂告诉我如何添加讲义或请老师生成，以便不用猜下一步。
6. 作为个人学习者，我希望看到章节和知识点目录，以便知道范围与当前位置。
7. 作为个人学习者，我希望目录较窄且可收起，以便给阅读留更多空间。
8. 作为个人学习者，我希望展开或恢复笔记和老师区，以便按当前任务组织界面。
9. 作为个人学习者，我希望拖动分隔条，以便按屏幕大小分配宽度。
10. 作为个人学习者，我希望讲义保持可读宽度，以便不会被其他栏挤没。
11. 作为个人学习者，我希望看到排版良好的标题、公式、代码、引用和表格，以便读懂讲义。
12. 作为个人学习者，我希望讲义和笔记左右并排，以便边看边记录。
13. 作为个人学习者，我希望 Markdown 笔记可编辑与预览，以便检查实际呈现。
14. 作为个人学习者，我希望笔记自动保存并显示状态，以便确定内容已落盘。
15. 作为个人学习者，我希望保存失败时文字仍在，以便可以重试或复制。
16. 作为个人学习者，我希望切换文件或离开课堂时未保存内容不会悄悄丢失，以便放心操作。
17. 作为个人学习者，我希望外部修改触发冲突提示，以便不覆盖 Obsidian 中的新内容。
18. 作为个人学习者，我希望在覆盖前比较两份内容，以便知道会丢掉什么。
19. 作为个人学习者，我希望用双链引用讲义和其他笔记，以便串起自己的理解。
20. 作为个人学习者，我希望链接在 DSH 与 Obsidian 中指向同一目标，以便跨工具使用。
21. 作为个人学习者，我希望缺失或有歧义的链接被指出，以便不会跳错内容。
22. 作为个人学习者，我希望选中讲义文字直接引用到笔记，以便保留原文与出处。
23. 作为个人学习者，我希望批注能回到真实位置，以便日后核对。
24. 作为个人学习者，我希望讲义改写后仍能看到当时引用的文字，以便旧批注仍可理解。
25. 作为个人学习者，我希望选中文字直接问老师，以便不用复制并重新解释背景。
26. 作为个人学习者，我希望发送前看到并移除提问上下文，以便不自动泄露无关笔记。
27. 作为个人学习者，我希望提问引用固定在发送时的版本，以便切课后仍知道当时问什么。
28. 作为个人学习者，我希望老师对话就在课堂里输入和输出，以便不用跳转。
29. 作为个人学习者，我希望保留真实工具呈现、Stop、提问和审批，以便掌控执行。
30. 作为个人学习者，我希望收起对话不停止回合，以便专心阅读后再看结果。
31. 作为个人学习者，我希望不同主题不会串会话或笔记，以便保持内容独立。
32. 作为个人学习者，我希望生成失败不损坏旧材料，以便已有学习不受影响。
33. 作为个人学习者，我希望老师生成的讲义有来源说明，以便区分参考与解释。
34. 作为个人学习者，我希望复杂概念才使用动态实验，以便不把所有课强行做成滑块。
35. 作为个人学习者，我希望实验的图形、数字与解释一致，以便不被错误演示误导。
36. 作为个人学习者，我希望实验不能读笔记或宿主信息，以便安全查看生成页面。
37. 作为个人学习者，我希望从实验返回原讲义，以便继续阅读。
38. 作为个人学习者，我希望 Canvas 展示知识关系并可点击进入内容，以便理解脉络。
39. 作为个人学习者，我希望看 Canvas 时仍可写笔记和问老师，以便不打断思考。
40. 作为个人学习者，我希望在 Obsidian 编辑画布或笔记后能重新加载，以便两边使用同一份文件。
41. 作为个人学习者，我希望重启后恢复主题、文件、位置、布局与会话，以便继续上次学习。
42. 作为个人学习者，我希望保存简短的本次小结与下一步，以便隔几天还能接上。
43. 作为个人学习者，我希望必要时用 DSH 原生能力打开文件，以便核对原始内容。
44. 作为个人学习者，我希望窄窗格中仍可切换各区，以便分屏使用。
45. 作为个人学习者，我希望键盘可以导航和调整布局，以便不依赖鼠标。
46. 作为个人学习者，我希望 AI 不擅自覆盖我的笔记，以便保留自己的理解记录。
47. 作为个人学习者，我希望插件清楚说明当前能力和限制，以便不把模拟或未验收当成可用。

## Implementation Decisions

### 身份与数据边界

- 全新独立插件，不依赖旧个人学习实现，不读取旧存储域，不迁移旧内容；复用 DSH 的公开宿主能力，不重建聊天运行时。
- 正文、笔记、课程脉络、学习目标与可读小结存为知识文件；插件持久层只保存身份关联、文件选择、布局、位置与会话绑定等运行元数据。可以重建的索引不是正文的第二份真相。
- 知识文件库由用户显式授权，现有目录可含其他 Obsidian 内容。默认模板不是改造整个 Vault 的授权，不创建或改写 Obsidian 配置，不扫描整库自动发送给模型。
- 新主题提供讲义、笔记、动态附件与课程脉络的默认组织方式；首版支持关联现有主题内文件，不自动搬动原文件。跨主题任意重组与完整文件管理不在首版。
- 目标、章节、知识点和文件不是同义词：目录体现学习顺序和章节结构，文件是内容载体。默认从受支持的文件夹、排序信息与标题推导目录，不先造复杂课程管理系统。

### B 阅读优先布局（用户已选方向）

- 保留 DSH 原生外壳，插件课堂为窄目录、宽主内容、右侧笔记与老师区。允许讲义与笔记并排，也允许四区同时展开；不能强迫笔记和老师二选一。
- 目录、笔记、老师均可独立收起，恢复入口始终可发现；拖拽改变分栏宽度，空余空间优先用于讲义。最小宽度与响应式阈值由实际浏览器验证决定，不以截图比例当硬编码值。
- 讲义、实验与 Canvas 在主内容区切换，目录、个人笔记和老师区不因切换而整体消失；切回保留各自内容和状态。
- 窄窗口改为分区切换，不挤出横向滚动；隐藏不等于取消后台任务。键盘可切换、收起、恢复和调整分隔条。
- 顶部不常驻巨大配置表单；知识库、空间创建等低频操作按需显示，课堂内明确当前主题、知识点与保存状态。
- 原型只确认 B 的布局方向；原型模拟对话、存储和审批不是生产能力，代码不能直接当作生产实现。

### 讲义、动态实验与来源

- Markdown 阅读须正确呈现常用结构与数学公式；不可把未受控 HTML 注入主文档。未知语法安全可读地降级，明确不支持项。
- 动态实验是讲义的关联内容，而非目录里无法返回的孤立页面；可从讲义打开并返回原位置。
- 实验在隔离边界运行，不获取宿主对象、笔记文件、凭据或任意网络权限；若未来需要资源或消息桥，另行声明权限，不用宽松沙箱补功能。
- 示例必须保持参数合法、图形读数和解释同步；实验不强制预测锁屏、关键词通关或自动掌握判断。
- 生成讲义区分来源与老师解释，保留可核对来源。文件成功落盘后才显示可用；失败保留旧文件，不写半成品，不静默覆盖重名内容。

### 笔记、双链与批注

- 个人笔记是 Markdown 文件，编辑、预览、自动保存和显式保存使用同一正文。切换笔记、空间、视图或关闭时，先保存或保留可恢复草稿；失败必须阻止无提示丢弃。
- 外部编辑以文件版本检测；冲突保留本地输入，展示双方内容供比较，再由用户选择重新加载或显式覆盖。串行队列和原子替换不能被宣称为跨进程锁，须明确剩余竞争风险。
- 双链兼容 Obsidian 的文件、别名、标题和已有块引用语义；生成链接优先使用无歧义的 Vault 相对目标。不同目录中同名文件、大小写与改名都需有明确结果，不能猜测目标。
- 选段批注保存纯文本原文与来源，追加到当前笔记并定位输入处；链接必须指向实际存在的标题或块。禁止只在渲染 DOM 中造锚点却声称 Obsidian 可跳转；没有稳定块时用真实文件/标题链接和原文摘录，不擅自改讲义制造块。
- 老师建议与个人文字分开。插件专用生成工具不写个人笔记；标准 Session 的通用文件/终端工具可能另有写权限，不能仅靠 Skill 或工具路径守卫承诺全通道只读。若不能由宿主权限覆盖全部通道，则 AI 不改笔记只能标为教学约定；交付必须披露并以真实审批/权限证据说明边界。

### 原生内嵌会话与提问上下文

- 首版默认一个学习主题绑定一个真实标准 DSH Session；主题内切知识点不另建会话，不丢输入。不同主题按独立身份恢复。
- 通过当前宿主公开 Session 引用、Provider 与嵌入式内容组合复用官方输入、输出、工具、Stop、提问和审批。不调用跳转式入口代替内嵌，不用模拟聊天兜底。
- 收起、切内容或视图卸载只处理自身引用，不自动取消 Host 回合；再次展开恢复真实状态。同一 Session 不建立重复可编辑输入根。
- 「问老师」把当前讲义引用、选段或用户明确选择的笔记片段追加至已有原生草稿，不能覆盖原草稿或立即自动发送。
- 发送前上下文可查看、移除；默认不附整库或完整个人笔记。未保存笔记片段取自用户选中的当前编辑文本，并标明未保存，不冒充磁盘版本。
- 每条已发送提问固定当时的主题、文件身份/版本与摘录；切换页面不改写过去的上下文。需要的摘录可作为消息内容由原生历史保存，不另造聊天数据库。
- 新建 Session 成功但绑定失败时重试不得重复建会话；生成失败、余额、权限与会话不可用均显示真实状态。Stop 不等于撤销已写文件。

### 文件访问、原生打开与 Canvas

- 文件读写由授权根内的受控 Host 边界执行：路径归一化、真实路径包含性、符号链接越界、大小限制、版本校验与原子写均在 Host 校验，不信任客户端路径。
- 复用已有 HTTP 应用入口与严格命令校验；工具调用以实际执行 Session 识别所属主题，不接受模型自报身份替代。文件读取与写入都受授权范围约束。
- Canvas 首版只读查看、平移缩放及节点导航；遵循 JSON Canvas 文件语义，不能擅改箭头含义。结构非法不渲染半张图，缺失的节点目标给出明确提示；知识关系不自动等于先修或掌握程度。
- 可读取既有 Canvas；AI 生成新脉络若纳入交付，应使用同样的文件写入与结构校验边界，不能只留下不可达的工具规格。
- Obsidian 可打开同一文件，插件内有重新加载入口或外部变更提示。提供在 Obsidian 中打开的动作不等于已嵌入其编辑器。
- 不另做源码查看器。DSH 原生打开文件是期望入口，但独立面板存在侧栏挂载限制；必须在真实宿主验证可用路径。若不可用，明确显示当前限制及 Obsidian/文件路径替代，不把尚未兑现的原生打开能力写成已交付。

### 持续学习的最低范围

- 保存主题目标、当前知识点及阅读位置；用户可显式保存本次小结与下一步到知识文件。AI 可提出建议，不能自动把它变成客观掌握结论。
- 不自动后台复习、不计算掌握概率；首版的连续性是文件、位置与对话能接续，而非完整教学推荐系统。

## Testing Decisions

### 测试边界与证据等级

- 沿用已确认的宿主 HTTP 集成与客户端渲染边界；纯逻辑单测只补路径、双链、排序和 Canvas 等难覆盖规则，不为每个模块增加新的测试入口。
- 将真实安装 DSH 的完整用户流程作为最终交付的最高验收入口。前版已经要求真实会话浏览器验收；本轮把它具体化为下表，不把它误写为每次提交都运行模型的浏览器自动化。
- 应用逻辑配真实临时目录、假的 storage facility 仅证明应用落盘，不等于真实 DSH 存储、插件激活或重启恢复。jsdom 配假的 Session/slots 只证明接线和状态，不证明流式、Stop 或审批。
- 测试断言外部可见行为与持久结果，不断言私有 state、CSS 类名、内部调用次数。前例为仓库已有原生公共接口/客户端产物检查、独立笔记插件测试与本插件的 HTTP/jsdom 测试；复用其方式而不继承未经核验的通过结论。
- 当前最高 seam 的细化验收矩阵待用户核对；文档可发布为 ready-for-agent，不以此标记验收已通过。

### 交付验收矩阵

所有必需项通过才可称「首版可交付」。未执行写未验证，不能以已知限制掩盖核心流程失败。降级或豁免须另经用户明确同意。

| 编号 | 必须演示的行为 | 通过标准与证据 |
| --- | --- | --- |
| G01 安装身份 | 准确发行包安装到隔离 DSH 环境并打开入口 | 记录宿主/插件版本、归档哈希、安装与激活结果；其他插件不被改写；不自动安装或重启正式环境 |
| G02 空间与文件 | 选库、新建主题、关联现有主题内讲义 | 实际文件可读，Obsidian 打开同一正文；无迁移旧域、无整库改写；不可访问状态可恢复 |
| G03 B 布局 | 桌面下并排看讲义笔记并与老师沟通 | 目录窄、讲义主导；辅助区独立收起恢复；拖拽有效；Canvas 仅切主区；截图与操作记录，不仅静态图 |
| G04 阅读实验 | 阅读含公式讲义，打开实验并返回 | 公式/代码可读；参数、图形、读数一致；回到原讲义位置；实验不能访问宿主、文件或网络 |
| G05 笔记保存 | 编辑、预览、切文件/主题、失败后重试 | 正文落盘；未保存输入不丢；可见保存状态；外部修改触发冲突并能比较、选择；至少一个真实外部编辑场景 |
| G06 双链批注 | 从两个不同目录创建引用并回跳 | DSH 与 Obsidian 指向同一真实文件/标题或块；无假块 id；同名歧义提示；摘录在来源改动后仍保留 |
| G07 提问上下文 | 选段问老师，查看/移除上下文后发送 | 不覆盖原生草稿；未保存笔记标注正确；未附整库；切换知识点不改变已发内容；真实回复能对应所附材料 |
| G08 真实会话 | 课堂内发消息、看工具、Stop、回答提问、拒绝/允许审批 | 无跳转、无假回复、单聊天输入根；收起/切课后后台回合可接续；给出实际交互记录，不能仅截图按钮 |
| G09 生成与边界 | 绑定老师生成讲义/实验，失败与跨主题负例 | 文件成功才显示可用；目录可刷新并进入新课；失败不毁旧文；拒绝跨主题写入；披露通用写工具对笔记的实际权限 |
| G10 Canvas | 读既有画布并点击讲义/笔记节点 | 标签和方向正确，目标可达；缺失/越界/非法结构明确；查看不发模型、不改画布；Obsidian 可编辑同一文件 |
| G11 冷恢复 | 两个主题分别学习后刷新及真实进程重启 | 主题、讲义/笔记、阅读位置、布局、Session 身份与历史正确恢复，不串内容；不是只重新构造内存对象 |
| G12 可操作性 | 常用桌面宽度、窄容器与键盘流程 | 无横向溢出；恢复按钮可发现；焦点不困住；键盘可切区和调整分隔条；记录实际尺寸与截图 |
| G13 原始文件 | 点击原生文件打开入口或已披露替代 | 记录真实宿主可用方式；不存在不提示的跳转或无效按钮；不能宣称未验收的侧栏集成已完成 |
| G14 学习接续 | 保存小结和下一步后再进入 | 可读小结落文件，目标与上次位置可见；不以浏览或一次答对标长期掌握 |

### 发布门槛

- 构建、类型检查、自动化测试、集成分支代码审查通过；所有待合并切片已整合，无冲突标记或仅存在子分支的必需能力。
- 最终验收覆盖双链与批注，不能遗漏其依赖；原工单图不自动等于本修订完整拆分，须做覆盖核对。
- 交付报告区分源码完成、替身自动化、真实安装和真实教学；记录未通过项与影响。不得用测试数量或子代理报告替代验收。
- 所有验收用隔离测试知识库与环境；正式安装、外部内容上传或费用敏感模型调用沿用用户授权与审批，不因发布规格默认授权。

## Out of Scope

- 旧插件兼容、旧数据迁移、双版本并行和旧实验台协议。
- 重写 DSH 聊天/执行/审批系统，或者以跳转、iframe 整站或假聊天绕过真实内嵌要求。
- 完整 Obsidian 编辑器、Canvas 编辑器、富文本笔记、独立源码查看器或完整文件管理器。
- 自动复习排程、掌握度算法、多导师、多设备同步、公共课程市场。
- 默认写入 Obsidian 配置、扫描整库作为模型上下文、未确认批量改写个人内容。
- 宣称本原型已经验证生产权限、文件安全或真实教学效果。
