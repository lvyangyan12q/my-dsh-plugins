# 07: HF 官方每日榜、热度选择与代理降级

## What to build

用官方 Hugging Face 每日榜提供热度信号：按 `?date=YYYY-MM-DD` 取当日榜、`upvotes` 排序，`paper.id` 映射 arXiv 取正文；与 arXiv 去重；代理不可用时整源跳过，用 arXiv 自排序补位，并在页面/run 记录标注。不启用镜像。

## Blocked by

- 04 翻译服务、缓存、pending 与预算
- 05 代理配置、健康检查与来源降级状态

## Acceptance criteria

- [ ] 只使用 `?date=` 形式，不把不带日期的跨天结果当每日全量。
- [ ] 票数参与论文选择；HF 条目正文一律回 arXiv，不抓第三方正文。
- [ ] 与 arXiv 结果按 arXiv id 去重，不产生重复条目。
- [ ] 代理缺失/健康检查失败时 HF 跳过，arXiv 补足配额，页面显示原因。
- [ ] fixture 测试覆盖日期榜解析、票数排序、去重、代理失败降级。
