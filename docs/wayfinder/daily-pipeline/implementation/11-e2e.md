# 11: 真实日期端到端验收与硬化

## What to build

用真实的一天跑完整条链路：抓取全部来源、选出 10 条、全文抽取与翻译、写入 digest、三种模式阅读；注入代理缺失、单源 403、翻译失败、文件损坏等故障；验证历史加载、配额、去重、页面状态与性能；形成可复现证据，并据此调整默认配额/预算。

## Blocked by

- 10 每日调度、运行状态与安装/回退

## Acceptance criteria

- [x] 真实日期至少 10 条，覆盖 arXiv、博客、中文源；同源/跨源无重复。
- [x] 三种阅读模式正确；英文源与中文源的对照列顺序正确；公式/图/代码不重复。
- [x] 故障注入：代理缺失只跳过 HF/OpenAI、单源失败不影响其他来源、翻译失败显示 pending、坏文件不被静默覆盖。
- [x] 7 天加载与 30 天保留边界正确；单日文件不超 8 MiB；页面在 10 条全文下可滚动、可筛选。
- [x] 产出验收记录（run 记录、页面截图或 DOM 证据、失败项清单）并据此更新默认配额/预算；未通过项保留为已知问题，不宣布完成。
