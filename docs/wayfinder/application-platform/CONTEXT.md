# 工作台应用平台

工作台是后续应用开发、管理与使用的共同基础。考公是接入应用，Agent 和 Skills 是独立管理的可复用能力。

## Language

**工作台平台**：承载多种应用的通用基础，服务于应用开发、管理和使用。
_Avoid_: 考公工作台、考公专属容器

**应用**：拥有自身业务规则和业务数据、接入工作台使用的功能集合。
_Avoid_: 把业务应用等同于 Agent

**页面**：应用中面向一个使用场景的界面。

**模块**：页面中承担展示或交互功能的区域。

**角色**：应用中承担某种职责的 AI 身份。

**会话**：用户与角色持续交流的记录，与展示模块区分。

**应用配方**：描述应用页面、模块、数据连接和角色关系的定义，不包含业务记录或对话历史。

**应用实例**：某应用的一次独立使用空间，拥有独立业务状态与角色会话关系。

**数据连接**：应用明确声明的数据来源关系，跨应用读取不等同于直接访问另一应用的数据。

**角色会话**：属于应用实例中某角色的持续交流，可由该实例的多个页面与模块共用。

**待发送上下文**：模块为角色任务准备、允许用户编辑或移除的信息，尚未发送给模型。
