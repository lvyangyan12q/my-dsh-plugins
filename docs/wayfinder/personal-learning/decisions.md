# 个人学习插件：已确认方向

## 2026-11-01 · 运行平台

用户明确选择 DSH。目标是个人使用的 DSH 学习插件；教学由 DSH 的会话与技能机制承载。现有 HTML 是独立、一次性的样式原型，尚未接入宿主。

## 已确认需求

- 个人自学。
- 使用 /teach 的教学方式，把抽象概念变成动画或交互 HTML。
- 通过知识图串联知识，支持系统学习。
- 样式借鉴 nexu-io/open-design。

## 尚未确认

- A 工作室、B 知识地图、C 沉浸课堂的取舍与组合。当前浏览器显示哪个方案不代表选择。
- 独立插件入口与现有工作台的具体接入方式。
- /teach 在 DSH 中的技能适配和调用合同；不能假设 Codex 技能目录已被 DSH 加载。
- 课程、概念关系、学习证据的数据结构和首版范围。
