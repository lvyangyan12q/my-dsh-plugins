# DSH 个人学习插件：交互课程、知识地图与持续学习

日期：2026-11-01。本地任务跟踪器中的规范来源。用户已确认个人使用、DSH 平台、/teach 教学方式、动画或 HTML、系统性知识图及 OpenDesign 风格。其余内容是基于讨论整理的首版实施建议，不表示用户逐项确认。ready-for-agent 表示规格已发布，不表示原型已选定或实现通过验收。测试边界待本轮用户核对。

## Problem Statement

用户希望在 DSH 中持续学习抽象知识。纯文字解释难以建立直觉，孤立的对话和网页又难以说明知识间的关系、先修要求及下一步方向。用户需要亲手操作的解释，并把这些解释积累为能导航、能复习、能继续学习的个人知识体系。

仓库已有工作台应用、原生角色会话、教学任务准备和生成内容展示等基础；考公是特定领域应用，不能直接等同于通用学习工具。当前学习原型只有内存示例和预置回复，未连接 DSH。现有 /teach 来自本机 Codex 技能目录，其教学组织方式可参考，但尚未证明能由 DSH 调用。

## Solution

提供一个面向个人的 DSH 学习插件。用户描述学习目标、提供资料或选择概念，得到有来源的学习路径；进入短小的交互 HTML 课程，调整参数、观察动画、回答问题，通过 DSH 原生教学会话追问。知识地图把概念、先修关系和课程连接起来，学习记录保存疑问、解释、练习结果和可追溯的掌握证据。

视觉采用 OpenDesign 的中性工作区语言：白底、浅灰面板、细边框、深灰文字与按钮，少量绿色用于选中和反馈。工作室、知识地图、沉浸课堂是现有三个布局候选；实现这些学习能力不要求同时实现三个完整页面，最终主布局仍需原型评审。

## User Stories

1. 作为个人学习者，我希望从 DSH 打开学习应用，以便在日常工作环境里学习。
2. 作为个人学习者，我希望输入学习主题和实际目标，以便课程围绕我想解决的问题展开。
3. 作为个人学习者，我希望说明已有基础，以便从合适的难度开始。
4. 作为个人学习者，我希望引用自己的资料及可信来源，以便讲解有依据。
5. 作为个人学习者，我希望区分资料内容与老师的解释，以便核对知识。
6. 作为个人学习者，我希望先看到课程安排，以便判断学习范围是否合适。
7. 作为个人学习者，我希望看到知识地图，以便理解概念间的联系。
8. 作为个人学习者，我希望区分先修、组成和应用关系，以便知道连线的含义。
9. 作为个人学习者，我希望点击节点查看概念、来源和关联课程，以便直接开始学习。
10. 作为个人学习者，我希望看到推荐下一步及原因，以便减少选择负担。
11. 作为个人学习者，我希望能主动选择其他概念，以便自由探索。
12. 作为个人学习者，我希望缺少先修知识时得到补充入口，以便解决理解障碍。
13. 作为个人学习者，我希望每节课聚焦一个小目标，以便快速获得具体理解。
14. 作为个人学习者，我希望用动画看到抽象过程，以便建立直觉。
15. 作为个人学习者，我希望调整实验参数并看到数值、图形同步变化，以便探索因果关系。
16. 作为个人学习者，我希望能暂停、逐步查看或重置适用的动画，以便按自己的节奏学习。
17. 作为个人学习者，我希望先预测再操作，以便检验自己的理解。
18. 作为个人学习者，我希望得到与错误有关的反馈，以便知道哪里需要修正。
19. 作为个人学习者，我希望用自己的话解释或完成变式问题，以便确认能否迁移知识。
20. 作为个人学习者，我希望围绕当前课程和实验状态追问，以便减少重复说明。
21. 作为个人学习者，我希望请求更直观的解释或先修补课，以便及时解决卡点。
22. 作为个人学习者，我希望发送前看到准备交给导师的上下文，以便编辑或移除不相关内容。
23. 作为个人学习者，我希望使用原生会话的停止、提问和审批能力，以便控制教学过程。
24. 作为个人学习者，我希望生成中、失败、取消和完成有明确区别，以便知道课程是否真的可用。
25. 作为个人学习者，我希望生成失败后仍能查看已有课程，以便不中断已有学习。
26. 作为个人学习者，我希望课程、参考材料和概念互相链接，以便随时回顾。
27. 作为个人学习者，我希望区分看过、能解释和能应用，以便避免误判掌握程度。
28. 作为个人学习者，我希望每项掌握判断关联实际证据，以便理解判断依据。
29. 作为个人学习者，我希望刷新或重启后恢复课程、记录和相关会话，以便持续学习。
30. 作为个人学习者，我希望不同学习实例的状态独立，以便多个主题不会互相覆盖。
31. 作为个人学习者，我希望切换视图继续使用同一份学习状态，以便不重复生成课程或创建会话。
32. 作为个人学习者，我希望缺少教学技能时知道缺什么及如何恢复，以便解决配置问题。
33. 作为个人学习者，我希望在较窄窗格中仍能操作课程，以便配合 DSH 的其他页面使用。
34. 作为个人学习者，我希望键盘能操作导航、实验控件和练习，以便不依赖鼠标完成学习。
35. 作为个人学习者，我希望浏览知识地图或调节本地实验时不隐式请求模型，以便掌握模型调用时机。

## Implementation Decisions

### 已确认方向

- 目标平台为 DSH，面向个人；不交付 Codex 插件作为本规格成果。
- /teach 负责教学方法与节奏，抽象概念通过动画或交互 HTML 呈现，知识图承担系统导航。
- OpenDesign 是视觉参考，采用独立实现，不复制其品牌身份。
- 当前原型是一次性设计材料，不能直接当生产实现；A/B/C 未选定，浏览器当前页面不构成设计确认。

### 首版实施建议与约束

- 沿用项目领域词汇：学习插件提供应用，应用实例拥有学习状态；页面、视图与窗格不新建业务归属。同一实例跨视图共享状态，不同实例隔离。
- 优先复用工作台既有应用接入与 DSH 原生会话入口；接入前核实当前宿主合同。独立菜单入口还是工作台内入口保持可调整，不以本规格宣称已决定。
- 将通用学习业务独立于考公；可复用其任务交接和所有权检查模式，不复制其考试规则或读取其私有数据。
- 教学能力适配为 DSH 可发现、可调用的 Skill。保留 /teach 的目标、来源、短课、参考材料、学习记录和共享组件组织方式；不得假定本机 Codex 路径在其他设备存在。启动教学前明确检查能力，缺失时提供可操作状态，不用预置回复冒充真实教学。
- 概念、课程、资料引用、学习记录、掌握证据分别有稳定身份，并归属学习实例。课程引用概念和来源，记录引用课程或概念以及实际回答；显示名称不作为身份。
- 知识边具有类型及方向；先修关系用于推荐顺序，组成或应用关系不自动成为先修。生成图标为可审查建议，先修循环和失效引用不能形成不可执行的推荐路径。
- 课程目录、知识关系与个人掌握记录独立保存；一个概念可对应多节课，一节课可关联相关概念。知识库检索图不直接视为学习路径。
- 教学任务优先沿用已有“准备、查看/编辑、显式发送”流程。准备内容包含当前目标、概念、资料引用及必要实验状态；切换节点、筛选和调节参数不发送模型请求。
- 原生会话以应用实例及教学角色关联；使用宿主既有消息输入、流式输出、停止与审批，不建设第二套模拟聊天运行时。
- 生成课程先形成可验证产物，再显示可学习状态。没有成功产物不能标记完成；失败或取消保留旧课程，不用空内容覆盖。重试避免重复附加同一课程。
- HTML 课程在隔离的展示边界运行。实验可以执行自身交互脚本，但不能读取宿主凭据、任意本地文件或跨实例内容；需要交回学习记录时使用受控、带实例与课程归属验证的消息接口。
- 共享样式及实验组件复用；每课提供明确目标、来源、解释、适用交互及理解检查。动画的控制方式随知识内容选择，不强迫所有课都使用滑块或视频。
- 学习记录区分接触内容、当次表现与长期保持；单次浏览、播放或答对一道题不自动判定长期掌握。首版提供证据与复习入口，具体评分算法不在本轮锁定。
- 保存目标、关联课程、概念关系、学习证据及会话关联；可恢复的当前位置与关键实验参数按课程能力保存。不得声称恢复任意脚本的全部运行状态。
- 视觉实现应有加载、空内容、能力缺失、失败与恢复状态；窄窗格可将并排区域改为顺序布局。生成内容修改和版本变化必须保留已有学习证据的可解释关联。

## Testing Decisions

以下为建议测试边界，用户确认状态为 pending。

- 主验收入口采用真实安装的 DSH 学习应用用户流程：打开应用实例 → 选择概念 → 准备并发送教学任务 → 生成并操作课程 → 原生追问 → 记录学习证据 → 刷新/重启恢复。以此作为尽量单一的高层测试边界，避免为每个组件发明新测试接口。
- 测试观察用户可见行为、保存后的内容与对宿主的外部交互；不把私有函数调用次数、源码字符串或快照相同作为功能完成标准。
- 测试覆盖学习应用整体及其现有宿主适配边界。模型输出可在自动化中使用固定课程样本，以稳定验证导航、交互与归属；正式验收另需至少一次真实 /teach 生成和原生会话证据，不将替身测试称为真实教学通过。
- 参考仓库现有教学任务面板测试：仅显示当前 Session 的任务，只有显式发送才提交。参考工作台生成入口的安装包测试：使用实际客户端工厂与原生导航合同；该类测试使用替身的部分不能替代真实宿主检查。
- 数据场景通过同一高层流程验证：两个实例隔离、多视图状态共享、刷新与重启恢复、过期课程引用、重复重试、失败保留原课。
- 课程展示边界仅补必要的聚焦测试：来自课程的写入必须验证归属，页面脚本不能突破隔离。这是高层流程难以充分覆盖的附加合同验证，而不是全代码逐函数测试。
- 固定的条件概率课程用于验收数值与图形一致性：100 个样本、B 为 40、交集 30 时，联合概率为 30%，条件概率为 75%；交集 0 与 40 的边界正确。若通用课程允许 B 为 0，应明确显示条件概率未定义，不能显示 0%。
- 检查动画控制、参数更新、题目反馈、键盘操作及窄窗格布局；操作图谱不触发模型，随堂追问携带正确课程上下文；停止与技能缺失具有真实、可恢复的状态。
- 验收证据写明宿主版本、插件版本、所测课程和真实/替身边界。已有原型的浏览器截图、DOM 检查与数值检查仅证明原型，不证明插件接入或生成质量。

## Out of Scope

- 班级、多人协作、教师管理、招生、付费和公共课程市场。
- 多位 AI 同学的模拟课堂及通用多角色编排系统。
- Codex 平台插件、对工作台平台本身的整体重构。
- 导入或迁移现有考公历史数据，自动修改其他应用业务状态。
- 首版覆盖所有学科、自动生成完整学科知识库或对学习效果作量化保证。
- 自动后台提醒、定时复习通知与复杂掌握概率模型；需要时另行明确。
- 把三套原型全部直接上线，或将预置回复当真实 AI 接入。
- 未经明确要求发布、安装到正式 profile 或重启用户宿主。
