# 03: 课程协议 v1 与参数桥

**What to build:** 课程可以声明自己的实验参数、读数与校验规则；宿主持有并校验这份协议，把参数与读数联动到画布上。边界值有明确定义。

**Blocked by:** 02 课程页实验台骨架

**Status:** complete

- [x] 课程协议覆盖：参数（id、范围、初值、步长）、读数（id、表达式或映射）、画布参数绑定、预测、复述四部分。
- [x] 宿主校验协议：参数越界、读数引用不存在的参数、预测正确项不在选项内、复述检查为空时拒绝该课，并给出可操作原因。
- [x] 参数变化时画布、读数与解释同步更新；读数保留合理精度。
- [x] 分母为 0 时显示“未定义”而不是 0%；`A∩B` 不允许超过 B；N 与 B 的联动关系在协议与界面一致。
- [x] 协议随课程版本保存，不把脚本、函数或客户端组件写入持久存储。
- [x] 非法协议被拒后，旧课程仍可打开。
