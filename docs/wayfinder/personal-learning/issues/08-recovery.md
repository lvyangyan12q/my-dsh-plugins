# 08: 参数与位置恢复

**What to build:** 回到一个学习空间时，恢复上次那一节与那组实验参数；刷新或重启宿主后同样成立，且不串空间。

**Blocked by:** 05 复述检查与学习证据

**Status:** ready-for-agent

- [ ] 重新打开学习空间恢复到上次那一节与当时的参数值。
- [ ] 刷新页面与重启宿主后恢复结果一致。
- [ ] 两个学习空间各自恢复自己的课程与参数，互不覆盖。
- [ ] 参数恢复只接受协议允许的范围；存储中的越界值被拒绝并给出可理解状态，不静默截断。
- [ ] 旧证据仍指向它记录的课程版本，不因课程更新而失去解释。
- [ ] 课程被删除或不可访问时明确提示，不静默新建一节课。
