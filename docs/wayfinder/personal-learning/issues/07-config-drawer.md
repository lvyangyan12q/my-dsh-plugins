# 07: 配置收纳与追问入口

**What to build:** 课程页不再平铺教学请求、待发送请求、资料与恢复；它们进入「⋯」抽屉。老师追问留在课程页，带上当前课程与参数，发往原生会话。

**Blocked by:** 02 课程页实验台骨架

**Status:** ready-for-agent

- [ ] 主界面不出现下拉框、刷新、准备、保存、发送等配置动作。
- [ ] 「⋯」抽屉分组收纳：教学请求与待发送、资料与来源、教学会话、恢复与历史；默认关闭，Esc 可关。
- [ ] 抽屉内的操作保留原有语义：发送前可编辑、显式发送、失败可见。
- [ ] 课程页的追问入口始终可用，消息携带当前课程 id、版本与已捕获参数，并进入同一原生会话。
- [ ] 窄屏下抽屉全宽滑入，不遮挡底部主行动。
