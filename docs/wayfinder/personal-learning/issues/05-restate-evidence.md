# 05: 复述检查与学习证据

**What to build:** 学生用一句话复述这一节的机制，宿主按协议检查要点并指出缺了哪点；通过后才出现“记下这一节”，并把这一轮的证据持久保存。

**Blocked by:** 04 预测门控

**Status:** complete

- [x] 复述输入为空时明确提示先写一句，不记入证据。
- [x] 检查结果列出命中项与缺失项，反馈具体（例如“提到了分母，没说它从 100 缩到 40”）。
- [x] 通过后才出现主行动“把这一节记下来，继续”；未通过时主行动不存在。
- [x] 证据记录课程 id、课程版本、参数快照、预测结果、复述命中项与时间，归属当前学习空间。
- [x] 单次通过只标记“本节完成”，不推断长期掌握；复习建议仍按证据计算。
- [x] 同一轮重复提交不产生重复证据；提交失败可重试且不丢已输入内容。
