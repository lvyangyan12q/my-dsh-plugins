# 06: /teach 生成适配

**What to build:** 让 `/teach` 生成课程时产出符合协议 v1 的交互课；不符合协议的产物被明确拒绝并说明缺什么，生成失败或取消时保留原来的课。

**Blocked by:** 03 课程协议 v1 与参数桥

**Status:** ready-for-agent

- [ ] 教学技能输出的课程包含协议：参数、读数、预测、复述四部分，且能通过宿主校验。
- [ ] 模型提交不合规课程时，拒绝原因可操作（缺哪个部分、哪个字段越界），并且不覆盖已存在的课。
- [ ] 生成中、失败、取消、完成四种状态在界面上可区分；失败或取消后旧课仍可学习。
- [ ] 重试不会重复收录同一课程版本，也不会把旧证据改挂到新版本。
- [ ] 至少一次真实模型生成产出可进入实验台的课程；替身样本只用于自动化。
