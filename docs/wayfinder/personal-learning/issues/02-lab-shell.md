# 02: 课程页实验台骨架

**What to build:** 打开一个学习空间后，课程页从“课程列表 + 请求面板 + 恢复面板”变成实验台：左侧画布区、右侧老师工作台三段（先猜 / 解释 / 复述）、底部唯一主行动位。

**Blocked by:** 01 rc.1 兼容并启用

**Status:** complete

- [x] 课程页主区域只有画布与工作台，不再平铺课程列表、刷新、请求编辑与恢复。
- [x] 工作台三段的顺序与可用关系固定：第二、三段在预测前不可用。
- [x] 没有交互协议的课以只读方式呈现，并显示“这一课不支持实验台”的可理解说明，不伪造控件。
- [x] 主行动在复述通过前不存在（不是禁用），任何时刻页面上最多一个主按钮。
- [x] 现有课程、答案与反馈数据仍可打开；旧数据不需要迁移即可进入只读形态。
