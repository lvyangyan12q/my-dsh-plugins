# 04: 预测门控

**What to build:** 每节实验课先让学习者选一个预测；没选之前，读数不可见、调参控件锁定、解释只显示占位。选完才解锁数字、控件与针对性解释。

**Blocked by:** 03 课程协议 v1 与参数桥

**Status:** ready-for-agent

- [ ] 协议含预测时，未作答状态下读数为未知、参数控件不可操作、播放/单步不可用。
- [ ] 解释区在未作答时只显示“先选一个”的占位，不出现会泄露答案的句子。
- [ ] 作答后立即解锁控件与读数，并按所选选项给出针对性反馈（对与错不同文案，指出错在哪一步）。
- [ ] 作答结果由宿主判定并记录，不依赖课程脚本自报。
- [ ] 参数继续变化不会撤销预测，也不会回退到未作答状态。
- [ ] 没有预测字段的课直接以可操作状态打开，不强制先猜。
