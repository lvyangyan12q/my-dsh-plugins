# 17 · 按已授权资料来源接入练习展示证明

状态：Host 必要接线与辅助回归已实现；新 K.5 官方安装及实际应用课堂/练习闭环待验收。K.4 冻结包不覆盖。

## 问题与范围

实际资料导入、只读授权和图片读取成功后，开始练习仍被来源 guard 拒绝。诊断确认两层原因：旧合成 v2 没有人工图示关联索引；此外新生产 Host 创建 `PracticeRounds` 时没有接入已有 `materialStem` / `materialOptions` 适配器，即使独立新来源具备正确索引也不能使用。

本切片不修改 `safePracticeQuestion`，不修改题干、选项、答案或评分快照，不重新评分，不给旧计划补证明追认，也不增加 SDK 能力。

## 实现边界

- 先通过当前工作台题库资源调用捕获 owner、connection、revision 和 rows，再匹配该 owner 已 applied 计划中的原题哈希；不能因另一资料库具有相同题号、相同正文或全局图根相同而借用证明。自身记录覆盖共享记录时，使用自身来源身份。
- 展示适配器只能读已确认计划固定的索引/图片路径及 SHA 收据。原本缺少的索引不会因之后新增文件自动生效。根身份、已有/缺失索引、原图、关联图与 record hash 均复核；读取结束再次核对资源授权及来源 revision。
- 保留原有显示转换规则。已证明图示仅追加/投影到展示；有完整来源索引的选项修复只影响展示。原题、原选项与答案保持原值，评分仍按原轮次快照。
- 撤销题库授权后新练习与该来源的题目快照读取拒绝，已有私有成绩记录保留不删除。文件/索引变化使用中文诊断，不隐藏错误或退回其他全局目录。
- 校验按当前计划与相关图像收据执行，不重新扫描整个旧资料库。大计划自身完整性哈希每次请求最多验证一次，不逐题重复序列化整个计划；没有对正式数据吞吐作承诺。

## 合成来源与证据

独立 v3 重新生成原创合成 PDF、PNG、题库和资料库来源，人工索引固定每题原 stem SHA、PNG SHA、真实本合成 PDF SHA 与第 1 页。PDF 明示 A=10/B=20；没有运行或声称运行 MinerU，兼容格式清单明确标记为手写合成。v3 原题库与 v2 所有值完全一致，原答案均为 B；v2 目录和其已应用库计划保持不变。

辅助回归使用真实 Native DomainFacility、应用/资源目录、新 materials-only 导入及显式只读授权，通过实际 production HTTP `practice/start` / `submit` / `read` 验证：

- 正确图示证明可签发十题、十个原答案 B 得分十题；签发结果不提前泄漏答案。
- 源选项包含合成污染标记时，仅有固定原 PDF/选项索引才能恢复干净展示，源选项与评分不改。
- 无索引旧计划、之后补索引、索引字节变化、关联/原嵌图片变化拒绝；单题 record 变化不能继续使用旧证明。
- 授权撤销后签发/读来源快照拒绝；捕获 rows 后中途撤销也拒绝，未产生半签发轮次。
- 相同题号/完全相同题目值的两个真实 owner 不能串用证明；全局配置切换后，原 owner 继续仅用自己的固定计划。
