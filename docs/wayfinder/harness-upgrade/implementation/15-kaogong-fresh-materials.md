# 资料保留与新部署接入 · 2026-10-25

用户选择全新部署，不迁历史会话，但要求之前的资料保存。本票只接入明确选定的资料；不把旧学习状态、老师Session或历史接管作为新部署前置。实现正在进行，不据此宣称已清点真实资料、已确认具体计划或已完成安装验收。

## 保留与数据边界

- 旧Native会话、旧学习记录、错题、成绩、练习/课堂进度及旧unknown接管回执保持原址，不迁移、不删除、不重算。新学习实例初始为空。
- 题库、讲义、原始图片、PDF、MinerU输入/输出及其读取路径分别清点。保留原始文件、引用、答案及来源证明，不通过移动目录、批量重写绝对路径或重新解析来冒充资料接入成功。
- 旧私人笔记、成绩和老师对话不是可共享资料。讲义或知识条目归属不明时默认保留私有，不因位于同一目录或sourceHome就整库导入/共享。
- 文件仍从核验的原址读取。明确资料集合根、题图根和MinerU作业根各自的含义；不从作业根猜测资料父目录，不扫描其他用户目录兜底。打包自带的样例与原用户资料分别记录。

## 实施路径与确认门槛

1. 离线或公开只读接缝生成资料清单，记录真实路径、条目数、引用关系、源revision与字节hash。不启动旧考公、历史apply/recover、文件修复或MinerU轮询；资料清点不打开原生老师会话。
2. 产出materials-only影响预览：所选题库/讲义及文件证据、被排除的私有或未知条目、原址读取根、待创建的新资料库目标及revision/fingerprint、可能新增的索引、只读授权对象和撤销/恢复边界。预览不创建目标、不授予读取权限，不写旧资料源。
3. 用户确认对应的具体资料计划后，才通过公开应用/资源接缝向新资料库写入已审范围的索引或记录。资料库和新学习实例分开，学习实例须显式只读授权；没有默认全库访问。
4. 源文件、来源revision、计划fingerprint、目标归属或当前授权变化时拒绝旧计划/旧读取。写入结果未知保留回执并先核对，不重复创建、覆盖新数据或整库回滚。
5. 使用全新学习实例完成资料选择、图片/讲义显示和实际教学/练习；撤销后后续HTTP、工具及任务读取均拒绝，刷新/重启保持原资料和新实例归属。

本轮需要确认的是写入新资料库目标的具体materials-only计划。旧Session A/B技术路线和逐会话交接均不实施、不再等待确认；这不把其他历史迁移计划的批准转作资料接入批准。

## 验收

- [ ] 清点题库/讲义/图片/PDF/MinerU实际读取关系，源文件与哈希保持；缺失或越界引用明确拒绝，不猜路径补齐。
- [ ] prepare/preview不创建实例、视图、授权或角色，不写旧学习/资料源；计划只含已选资料范围。
- [ ] 正式资料写入前先展示具体影响预览并取得该计划确认；独立合成资料与正式资料的批准和证据分开。
- [ ] 新资料库接入与新学习实例的显式只读授权、私有排除、跨实例拒绝及撤销均通过生产Host回归。
- [ ] 最终归档在实际安装的DSH中完成资料引用、图片、教学和练习闭环，刷新/重启后原址仍可读，旧学习记录与会话原件不变。
- [ ] 记录包版本、SDK协议、实际文件清单和回退边界；不覆盖已冻结Worktable `.3`或考公 `.1`。
