# 资料保留与新部署接入 · 2026-10-25

用户选择全新部署，不迁历史会话，但要求之前的资料保存。本票只接入明确选定的资料；不把旧学习状态、老师Session或历史接管作为新部署前置。生产源码已合入，具体资料计划和新归档实页仍待验；不据此宣称已确认资料计划或已完成安装验收。

## 保留与数据边界

- 旧Native会话、旧学习记录、错题、成绩、练习/课堂进度及旧unknown接管回执保持原址，不迁移、不删除、不重算。新学习实例初始为空。
- 题库、讲义、原始图片、PDF、MinerU输入/输出及其读取路径分别清点。保留原始文件、引用、答案及来源证明，不通过移动目录、批量重写绝对路径或重新解析来冒充资料接入成功。
- 旧私人笔记、成绩和老师对话不是可共享资料。讲义或知识条目归属不明时默认保留私有，不因位于同一目录或sourceHome就整库导入/共享。
- 文件仍从核验的原址读取。明确资料集合根、题图根和MinerU作业根各自的含义；不从作业根猜测资料父目录，不扫描其他用户目录兜底。打包自带的样例与原用户资料分别记录。

## 实施路径与确认门槛

1. 离线或公开只读接缝生成资料清单，记录真实路径、条目数、引用关系、源revision与字节hash。不启动旧考公、历史apply/recover、文件修复或MinerU轮询；资料清点不打开原生老师会话。
2. 产出materials-only影响预览：所选题库/讲义及文件证据、被排除的私有或未知条目、原址读取根、待创建的新资料库目标及revision/fingerprint、可能新增的索引、只读授权对象和撤销/恢复边界。预览不创建目标、不授予读取权限，只写新计划元数据，不打开或修复目标业务域，不写旧资料源。
3. 用户确认对应的具体资料计划后，才通过公开应用/资源接缝向新资料库写入已审范围的索引或记录。资料库和新学习实例分开，学习实例须显式只读授权；没有默认全库访问。
4. 源文件、来源revision、计划fingerprint、目标归属或当前授权变化时拒绝旧计划/旧读取。写入结果未知保留回执并先核对，不重复创建、覆盖新数据或整库回滚。
5. 使用全新学习实例完成资料选择、图片/讲义显示和实际教学/练习；撤销后后续HTTP、工具及任务读取均拒绝，刷新/重启保持原资料和新实例归属。

本轮需要确认的是写入新资料库目标的具体materials-only计划。旧Session A/B技术路线和逐会话交接均不实施、不再等待确认；这不把其他历史迁移计划的批准转作资料接入批准。

## 已实现的用户入口与资料边界
### 已确认边界

按用户 2026-10-25 的决定，全新安装，不处理历史会话。旧题库、原始资料和私有讲义保留；不迁移笔记、成绩、学习计划、待发任务或老师会话。不写、搬、删旧源文件，也不修改原题、答案或重新评分。

### 用户入口与影响

1. 插件设置显式配置 `materialSourceHome`，指向原题库和知识资料的 DSH 数据目录；图片、原 PDF 与 MinerU 根目录仍使用显式资源配置，不猜测父目录。
2. 创建一个空的“考公资料库”实例，在该实例内选择“接入已有题库与资料”。
3. 只读预览只读取 `kaogong_bank` 与 `kaogong_knowledge` 两域；旧角色或练习文件损坏不会阻塞此预览。预览固定源文件哈希、原始路径、目标实例与修订和图片来源证明。预览只写新计划元数据，不打开或修复目标业务域。
4. 核对具体数量、目标与指纹后显式确认。导入只写新资料库的题库/知识元数据与恢复凭据；原文件不复制，所有图片仍由精确原引用及哈希证明读取。
5. 有明确原始来源证明的资料可以通过工作台显式只读授权给学习实例。私有或未证明来源的讲义在资料库自身可读，始终过滤出跨实例 `materials` 资源。笔记留在旧源，不进入资料库。
6. 写入结果未知时，目标正常读取及资源访问保持隔离；刷新或重启不自动恢复。可以从同实例另一个有效视图显式确认同一计划，核实原值后继续，不能覆盖已变化或不属于该计划的内容。

### 新部署不激活的历史功能

生产入口不再创建旧学习/老师会话接管 owner，不注册 `/api/kaogong/adoption`。旧完整迁移模块与回归保留为历史代码；测试通过明确的 `historical-host-fixture` 挂载，不提供生产隐藏开关。已有旧接管凭据仅保留未知目标隔离和已接入资料的原始图片证明读取，不能将其自动恢复。
