## Question

依据考公迁移研究，哪些题库、图片和讲义可以显式共享，哪些学习记录、角色任务及原生会话必须属于独立实例？旧 default 学习如何被显式接管，并在不复制成绩、不改变旧会话 cwd、不重建老师的情况下继续学习？

需要决定旧记录的入口、接管前影响预览、旧身份到新实例的映射、未接管/失败时的保留行为，以及新实例的初始状态。不可由研究者替用户选择历史资料或默认项目；如涉及关键交互，再按需制作最小原型。
