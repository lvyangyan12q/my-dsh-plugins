## Question

在用户授权的独立 DSH 验收实例中，如何取得可用模型及必要执行条件，使应用生成、标注执行、真实教学、审批、提问、Stop 和流式恢复能够验收？先只读确认最新模型配置与服务错误，再形成需要用户操作的最小清单；不复制正式凭据、不提交秘密、不反复重试已确定的同一授权错误。已有配置问答尚未完成，不另行重复索要密钥。记录可用条件或真实阻碍后才能决定下游验收路线。
