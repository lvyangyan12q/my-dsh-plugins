# 08 原 PDF 逐项选项核验与解题批注阻断

2026-10-11。延续上一份单项证明，对私有页面匹配的候选逐页视检，再独立转录受影响选项正文，规范化对比原选项仅去掉明确终端广告后的文本。私有题号、关联索引、原题文本、PDF 和页面图不提交。

18 个宽匹配候选中，1 个是合法“微信扫码”选项，不能当广告清理；实际广告候选为17个。现在10个选项正文已与原 PDF 逐项匹配（此前1个，本次新增9个），关联索引只保存在隔离验收根目录。这里证明的是受影响选项正文及终端广告，不代表整道题所有内容正确。

原 PDF 确认一项广告使用全角逗号而非顿号。公开 Host 发题测试先失败，再将已认证关联中的精确终端模式改为仅允许这两种分隔符。仍须题号、原题干和整个原选项数组哈希都匹配；未知尾随文字、其他广告形式、未关联记录均不改。

父层实际浏览器又发现“花生批注：”解题信息泄漏。新公开命令回归先证实带批注的题干和选项仍被发题，然后以该明确标记阻断资格，不删除或猜写正文。旧未提交轮次读取也返回409并提示重新开始；仍保留原始记录、快照、提交评分与已提交历史读取。历史备份中283行有该明确标记，其中177行已经审核为approved，不能继续视为安全练习题。

10条私有选项关联中，1条存在其他解题批注，被新资格规则阻断。另9条实际历史记录通过当前源码 Host 的发题→按原答案提交→关闭JSON存储→重启读取，公开选项投影正确，原库、原评分快照、原答案与解析不变，备份哈希不变。这不是安装浏览器验收。

仍有7个广告候选未认证修复：1个已审核题的选项正文与PDF存在OCR差异；6个未审核题含页码、饼图占位、题面或材料混入等问题，其中3个尚无确定原PDF页身份。页面中的广告位置不能证明这些残留数字或占位符属于正文，不能只剥广告后假称修好。旧绝对图片引用也未因此全部放行。
