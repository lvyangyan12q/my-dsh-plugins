# 08 部分源码验证：书目来源中的“解析”不应屏蔽正文正常的题目

状态：仅定向源码/Host 夹具回归及只读资格核对；工单保持 open，未替代实际安装浏览器验收。

## 问题与公共接缝

原门禁把题干、选项、来源连在一起后匹配任意“解析”。因此含名师解析字样的书目来源标题会使正常题目无法开始练习。只读原有已审核数字推理记录显示十题均由来源标题触发，题干和选项没有该门禁词或图示占位。本修复不修改题库、来源、答案、审核状态或原学习记录。

按已确认公开 `PracticeRounds.start/submit` 接缝做 RED→GREEN：以不包含私有题文的合成题，保留同类书目来源，旧代码在开始时抛出“匹配题目的图表或选项尚未通过来源核验”；新代码能发题，返回来源原文、完整题干和选项，提交前隐藏答案字段和解释，提交后按原答案评分，原题记录保持一致。

## 最小变化与安全边界

题干/选项继续匹配原有答案、解析词与答案列表。来源仅对括号完整包围的“名师解析”或“华图名师解析”书目描述作正向识别（中文或英文圆括号）；其余来源中的答案、解析、解答词、英文解答标签和答案列表保持拒绝。不按“无冒号”放行未知解析文本。跨字段教师批注门禁、未核验图示/本地图片、选项广告/占位、正确答案与选项匹配规则均不变。

公开发题回归另含十五种拒绝情形：题干/选项中的答案与解析、题干/选项/来源的教师批注、来源的参考答案/解析标记/英文答案/答案列表、缺图与全角图示占位、广告选项、答案无法匹配。它们都从新轮次排除，暂缓数量正确，题库原记录保留。该回归不宣称能识别任意自然语言解答泄漏。
