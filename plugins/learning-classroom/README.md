# 学习课堂

DSH 的个人学习插件：从一个本地**知识文件库**开始，为每门课建立一个学习空间，课堂里同时容纳课程目录、讲义、个人笔记与老师对话。

本版本（工单 01）交付课堂骨架与知识库接入：

- 侧栏「学习课堂」入口与主面板。
- 首次使用选择一个已存在的本地目录作为知识文件库，绝对路径保存在插件状态里。
- 创建学习空间时，在知识库根下建立同名文件夹：`讲义/`、`笔记/`、`附件/`，并写入默认笔记 `笔记/我的笔记.md`。
- 未选知识库、目录不可访问、目录不可写时给出可操作状态，不把裸异常抛到界面。
- 主面板四区骨架：课程目录、讲义、我的笔记、老师对话。对话区是明确的未连接占位，不伪造聊天。
- 重启宿主后，知识库选择、学习空间列表与当前空间仍然保留。

尚未实现（后续工单）：讲义读取与渲染、笔记编辑与版本冲突、老师会话内嵌、课程脉络、动态实验。

## 存储与文件

- 存储域：`learning_classroom` v1，只保存知识库根路径、学习空间绑定与当前选择；讲义、笔记、脉络正文永远是知识库里的文件。
- 不读取也不写入已删除的旧个人学习存储域。
- Host 侧提供唯一 HTTP 入口 `/api/learning-classroom`：`GET` 读取状态，`POST` 发送带 `action` 的命令。未知 action、未知字段、非 JSON 请求一律拒绝。
- 所有文件路径在 Host 侧重新校验：必须是知识库根内的相对路径，拒绝 `..`、绝对路径、盘符、UNC 与越界符号链接；越界报错而不是静默修正。
- 创建学习空间先写入隐藏的暂存目录，再整体重命名为目标文件夹；同名目录已存在时复用已登记空间或明确拒绝，不留半写结果。

## 开发

```powershell
pnpm install
pnpm build
pnpm test
```

测试使用 `node:test` + `tsx`：Host 侧在真实临时目录上走 HTTP 与落盘断言，客户端用 jsdom 渲染主面板并注入假请求边界。
