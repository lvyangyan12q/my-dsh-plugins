# 04 确认页：找用户确认和补充什么

Type: grilling
Status: resolved
Blocked by: 03

## Question

点「处理」后窗口3 弹出的确认页，要定：

- 自动带出哪些：缺陷编号/标题/状态/优先级/描述、服务/版本、环境主机、匹配到的 SSH 连接与项目、本地仓库路径、建议容器。
- 哪些必须由用户补：缺失的 localPath、服务→项目映射、容器名、日志时间窗、复现补充说明。
- 校验规则：路径存在、是 git 仓库、SSH 配置完整、映射完整；缺项时按钮禁用还是允许带警告派发。
- 交互：默认值怎么选、保存/写回哪些、能否「本次不写回」。
- 「确认并派发」之后窗口3 进入什么状态。

## Answer

决策已并入 [窗口3 规格](../spec.md)：确认页自动带出缺陷/服务/主机/SSH/项目/`specRef`；缺 localPath、服务映射、容器、日志时间窗可现场补并写回；校验路径、git、SSH、spec；确认后进入第 1 轮方案（先方案、后代码）。
