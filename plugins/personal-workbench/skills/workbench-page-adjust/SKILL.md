核对应用、实例、页面、模块、请求身份、旧产物位置与新输出路径。读取旧页面和 ../shared/module-template.html，定位本次需求对应的内容或交互。修改范围不明确时先确认范围。

将调整后的完整页面写到本次请求指定的新输出文件，保留旧产物供恢复。保留真实数据来源、原有可用资源引用、表单状态和无障碍标签；采用模板公共样式，CSS 与 JavaScript 内联。用户要求替换的部分按需求更新，其余内容保持一致。

验收：在目标模块显示新页面，操作受影响的按钮、筛选和布局；刷新并检查仍是本次模块与请求的产物。报告变化、输出路径、请求 ID 和实际显示结果。界面或资源尚未验证时明确留下对应未完成项。
