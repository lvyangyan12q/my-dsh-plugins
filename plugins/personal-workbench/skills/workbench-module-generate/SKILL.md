---
name: workbench-module-generate
description: 根据工作台目标模块的需求生成独立 HTML 页面，使用指定请求输出路径与统一组件。
---

先核对任务提供的应用、实例、页面、模块、请求 ID、工作目录和精确输出路径。缺少目标身份或路径时，询问缺失字段后再写文件。

读取 ../shared/module-template.html，使用其中的颜色、字体、卡片、按钮、筛选和状态样式。先判断需求能否由网站、原生 DSH 对话、资源或内置数据模块满足；需要独立交互页面才生成 HTML。

把模板的 CSS 与 JavaScript 内联到输出 HTML；标题和内容使用实际需求，统计使用提供的数据，缺少数据时显示空状态。用户资料的文本用 textContent 等安全方式写入页面。保留引用的真实资料路径，图片等资源采用平台已提供的可加载引用；检查资源在目标 iframe 中可以访问。

仅写入指定请求的输出文件。模块身份以 ID 为准，名称变化不改变归属。修改其他文件或权限前遵循原生审批；拒绝后停止相应操作并报告原因。

验收：打开目标模块的真实 iframe，检查内容、交互、窄屏、滚动和资料加载。实际显示验证完成后报告成功；只写文件时报告“等待工作台显示验证”。报告文件位置、请求 ID、已验证行为与未通过项。
