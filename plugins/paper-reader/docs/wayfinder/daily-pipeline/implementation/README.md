## 依赖图

```text
01 ── 02 ── 03 ── 04 ── 06
              │      ├── 07 ──┐
              │      └── 09 ──┤
              ├── 05 ─────────┤
              └── 08 ─────────┤
                              └── 10 ── 11
```

`05` 与 `08` 只依赖 `03`；`07`/`09` 依赖 `04`+`05`；`10` 汇聚全部来源与代理，`11` 做真实日期验收。取下一张：**所有 blockers 已完成**的工单，按编号顺序。

## 状态

每张工单的 frontmatter：`status`（open/closed）、`assignee`（认领后填写）、`blocked_by`。开工前先认领，完成后勾选验收项再关闭；关闭不等于验收通过，真实运行证据单独记录。

查询前沿（PowerShell）：

```powershell
pwsh -File docs/wayfinder/daily-pipeline/implementation/frontier.ps1
```

本目录不是 wayfinder 地图子票，不带 `wayfinder:*` 标签；这些是可直接认领的实施工单（`ready-for-agent`）。
