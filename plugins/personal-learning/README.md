# DSH 个人学习插件

独立 DSH 菜单入口，A 工作室与 B 知识地图；无需 Worktable。目标宿主为 DSH 0.2.2-rc.1，不宣称其他版本兼容。

## 使用

在测试 profile 安装生成的 tgz，打开“个人学习”。创建学习空间，选择已登记的工作目录并打开原生教学会话。填写资料和需求，在教学请求面板预览/编辑后显式发送。导师使用打包的 personal-learning-teach 技能及课程/地图/反馈工具提交产物；返回学习页刷新查看。

课程使用隔离 HTML，支持协议的课程可保存实验参数；其他课程明确使用人工观察。地图草稿经确认后保存，节点进入完整课程、随堂追问与理解练习。记录关联课程版本，单次回答不等于长期掌握。原生会话拥有 Stop/提问/审批；任务恢复区区分原生执行状态与课程产物状态。

## 验证与打包

在本插件目录运行 `node scripts/build.mjs`、`node --test tests/*.test.mjs`。真实宿主声明门禁需要设置 `DSH_SOURCE` 为已构建的官方 alpha.2 安装；未设置时对应测试跳过，不代表通过。`node scripts/installed-gate.mjs` 的环境和产物见 INSTALLED-EVIDENCE.md。

HTTP 公共入口为 `/api/personal-learning`，所有持久写入与模型工具共用串行分发，绑定实例及原生会话。学习数据由 DSH storageDomain 保存，不使用原型的内存数据。
