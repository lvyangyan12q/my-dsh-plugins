# 04: 知识点主动回忆完整闭环

**Parent:** [学习与复习体验改版](../../../docs/tickets/08-learning-review-experience-spec.md)

**What to build:** 学习者手动确认将知识点加入复习中心，先回忆、揭示获准要点、自评并确认，得到下一日期和可恢复历史。

**Blocked by:** 02：按知识点学习并形成可信覆盖

**Status:** ready-for-agent

**Acceptance criteria:**

- [ ] 初次 1 天；未记住/模糊/记住分别从实际确认起计算 1/3/7 天；不使用错题巩固阶段。
- [ ] 到期、逾期、未来、科目/知识点筛选和空队列可用；未记住仍可完成本次回忆活动。
- [ ] 自评不计客观正确率、不新增或撤销已学；同周期重试不重复入队或推进。
- [ ] 无要点或授权失效明确反馈；返回、刷新和重启恢复草稿与本次周期。

**验证约定：** 沿用已确认的 Host、Native、页面确认与准确发行包测试边界；只记录实际执行结果。保留档案隔离、资料授权、真实评分与历史快照。按批准原型实现本票对应交互，验收证据完成前不勾选。
