# 08: 准确发行包的独立闭环与恢复交付

**Parent:** [学习与复习体验改版](../../../docs/tickets/08-learning-review-experience-spec.md)

**What to build:** 在临时独立 home 安装准确发行包，完成完整学习和两类复习路径，并验证重启、原位升级/重装及共存边界，形成可复核交付记录。

**Blocked by:** 07：从真实学习进度调整未来安排

**Status:** in-progress（alpha.3独立实装已验，共存及部分冲突恢复条件未验）

**Decision gate:** 2026-11-05 已定稿，见对应决策票 Resolution；实施仍须满足本票依赖。

**Acceptance criteria:**

- [x] 固定源码、宿主实际提交/版本、包哈希；构建用物理隔离依赖，安装文件与准确包逐文件一致。
- [ ] 无工作台环境真实走目标→预览确认→学习→评分/反思→完成→两类复习→进度调整；不同档案、重复确认、恢复与冲突均有证据。
- [x] 验证原生私有 Skill、问题卡片、拒绝/允许一次审批、Stop、唯一输入框及桌面/窄屏；不把静态原型或模拟响应当实装。
- [ ] 共存只验证独立入口、工具/会话边界，不引入工作台依赖；原始资料、快照、Session/cwd、其他插件与新增学习记录受保护。
- [x] 记录未测范围、回退材料和启动方式；不启动用户日常 3080，不公开发布、不推送。正式安装若另行要求，先完成保护与现场核对。
- [x] 浏览器 DevTools 验收；原生鼠标/窗口另行确认，人工 IME 与未测平台不记通过。

**验证约定：** 沿用已确认的 Host、Native、页面确认与准确发行包测试边界；只记录实际执行结果。保留档案隔离、资料授权、真实评分与历史快照。按批准原型实现本票对应交互，验收证据完成前不勾选。
