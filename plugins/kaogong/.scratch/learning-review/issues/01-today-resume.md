# 01: 从今日继续同一项真实任务

**Parent:** [学习与复习体验改版](../../../docs/tickets/08-learning-review-experience-spec.md)

**What to build:** 今日显示真实任务与继续入口，进入任务所属原生课堂或练习；返回、刷新继续同一记录和草稿。先在此窄路径内提取共用开始/恢复操作，再接新页面，不新增另一套课堂服务。

**Blocked by:** None (无实施票依赖)；决策门槛：导航恢复合同尚未定稿

**Status:** ready-for-agent

**Decision gate:** [导航恢复合同](../../../docs/wayfinder/learning-review/issues/05-navigation-recovery.md) 仍开放；本次生成仅批准拆分，不关闭决策。门槛完成后才可执行本票。

**Acceptance criteria:**

- [ ] 任务身份而非老师或数组下标决定进入对象；重复开始不生成重复课堂、轮次或 Session。
- [ ] 无档案、无计划、无今日任务有可操作空状态；旧资料、自由练习、外部模考、角色管理入口仍可达。
- [ ] 保留完整原生对话、唯一输入框及任务右栏；桌面、窄屏与键盘返回可用。
- [ ] 通过 Host/页面验证恢复、档案隔离和既有草稿；实施前后公共行为保持一致。

**验证约定：** 沿用已确认的 Host、Native、页面确认与准确发行包测试边界；只记录实际执行结果。保留档案隔离、资料授权、真实评分与历史快照。按批准原型实现本票对应交互，验收证据完成前不勾选。
