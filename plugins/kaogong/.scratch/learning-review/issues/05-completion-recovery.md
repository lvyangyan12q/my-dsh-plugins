# 05: 一次收尾确认与失败后恢复

**Parent:** [学习与复习体验改版](../../../docs/tickets/08-learning-review-experience-spec.md)

**What to build:** 课堂任务面板集中展示依据、总结、缺项和可选复习，学习者确认后收到准确回执；发生部分成功时继续完成剩余步骤。

**Blocked by:** 01：从今日继续同一项真实任务、04：知识点主动回忆完整闭环

**Status:** implemented-pending-release-acceptance

**Decision gate:** 2026-11-05 已定稿，见对应决策票 Resolution；实施仍须满足本票依赖。

**Acceptance criteria:**

- [ ] 仅自动关联唯一且匹配的真实依据；歧义候选用标题/时间供选择，不要求手填 ID。
- [ ] 保存草稿、Stop 或模型建议不完成任务；保留各任务真实练习/反思条件，未答规则不被悄悄更改。
- [ ] 完成已保存但入队失败时明确显示两者结果；重试不重复完成、记分或入队，刷新可恢复未完成效果。
- [ ] 可不加入复习，也可稍后加入；首次日期可见，下一项和返回今日均可用。

**验证约定：** 沿用已确认的 Host、Native、页面确认与准确发行包测试边界；只记录实际执行结果。保留档案隔离、资料授权、真实评分与历史快照。按批准原型实现本票对应交互，验收证据完成前不勾选。
