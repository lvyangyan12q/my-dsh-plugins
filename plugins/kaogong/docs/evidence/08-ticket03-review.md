# 03 错题复习模式实施证据

2026-11-05。独立分支 codex/kaogong-review03，基于集成分支 33dce36，提交前同步集成 tip。

## 实现

既有 errors 公开入口增加 mode=review。GET 用白名单投影，仅当前未确认作答存在时返回解答；旧历史不混入复习响应。复习命令返回的领域记录也剔除历史，默认历史查阅保持完整。评分、阶段、原快照和权限 gate 不变。

页面明确区分历史和复习，先重新作答再揭示。草稿按明确 transport 档案、错题发生项、复习 dueAt 周期隔离，恢复答案、反思、提前复习确认与请求 ID；未知网络结果可重试同一请求，成功确认仅清理该周期草稿。无档案 transport 的历史兼容入口不持久保存以免串档。

## 验证

- Host 公开用例新增揭示前隐藏断言：red true !== false；GET 投影后 green。
- 确认响应不携带旧历史断言：red true !== false；POST 投影后 green。
- Host 原始错误保留及计划复习用例 2/2 通过，包含跨档案、授权撤销、阶段推进和原评分不变。
- 页面新增模式入口：red 缺少按钮；加入模式后通过。
- 离开复习再返回草稿：red undefined !== true；周期草稿实现后通过。
- 网络失败后切页重试 requestId 相同回归通过。
- 完整 client 25/25 通过；diff whitespace 检查通过。
