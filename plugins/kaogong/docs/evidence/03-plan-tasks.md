# 03 计划、任务与完成依据

源码分支 `codex/kaogong-ticket03`，基于02并合并04。2026-10-27验证。

新增每档案独立的 `kaogong_study_plan` 增量聚合；未配置日期为null，不显示默认倒计时。目标按考试日、模块数与科目权重预览基础/强化/冲刺；计划差异、容量溢出、稳定任务ID、延期/追加和确认历史持久保存。按日/周/全程查看。只有页面明确确认才应用提案，过期revision拒绝覆盖。未来调整保留逾期、进行中及已完成任务，未排入任务不消失。

任务开始先持久保存intent，同一开始请求保留同lesson/round；课堂明确显示是否需要练习。无练习学习任务保存总结后由学习者确认；要求练习的学习任务和练习任务核对所属任务的已提交轮次及要求的错因反思。原生空闲/Stop不完成任务。总览/模型进度读取新任务，题目判分与任务完成率分开；外部模考单列自报，不作为系统判分。

模型 `kaogong_plan_set` 仅产生待确认草稿，`kaogong_plan_done` 仅返回建议；不提供模型确认接口。旧日期/数组索引HTTP打卡返回410。现有全局计划与原始成绩不被复制改写。

公开Host验证包括鉴权/所属view、预览不生效、手动确认；无练习课堂总结确认；授权源真实发题、隐藏答案、同任务同轮重试、未提交/未反思拒绝完成；要求课后练习课堂关联轮次并回写任务。页面验证必须先预览再单独确认。附加JSON持久Owner验证稳定ID、未来重排、容量和外部成绩分离。
