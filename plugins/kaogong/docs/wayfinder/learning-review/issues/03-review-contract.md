## Question

知识点主动回忆的未记住/模糊/记住怎样影响下一日期和阶段？提前复习、反复失败、已巩固后自主复习如何处理？怎样保留历史查阅答案能力，同时让本次复习先作答再揭示？

现有事实：错题发生项已有独立历史、客观判分和 1/3/7 天规则；主动回忆尚不存在。错题页和 GET 响应当前提前展示答案，现有测试也断言这一历史查阅行为。不能将自评装入 answer/correct 或只隐藏页面文字。

关闭需要：用户核对明确状态表和日期例子；区分自评/客观成绩、队列/日程；确定历史查阅与复习响应的揭示边界。规格此前提出的自评回退规则属于待确认建议。优先在原有公开 Host/页面测试入口落验证条件，不新增平行业务。

## Discussion

2026-11-04 已认领。批准原型明确展示主动回忆的未记住→1天、模糊→3天、记住→7天，但注明为演示规则；现有正式错题则为首次1天后，连续答对并确认后分别间隔3天、7天，第三阶段通过为已巩固，答错回待订正并1天后重新开始。两者不应混成一个 stage/correct 模型。

提交用户核对的正式版建议：

| 类型/动作 | 确认后结果 | 下一安排 |
|---|---|---|
| 知识点首次加入 | 等待主动回忆，不改学习完成状态 | 1天后 |
| 主动回忆：未记住 | 记录主观自评，不记为客观错误 | 本次确认起1天后 |
| 主动回忆：模糊 | 记录主观自评 | 本次确认起3天后 |
| 主动回忆：记住 | 记录主观自评，不宣称永久掌握 | 本次确认起7天后 |
| 错题答对且反思确认 | 沿用既有三阶段 | 前两阶段分别3天、7天后；第三阶段已巩固 |
| 错题答错且反思确认 | 沿用待订正、重新开始 | 1天后 |

- 主动回忆持续按本次自评安排，不套错题“三次正确即已巩固”；每次确认只更新一个周期。重复确认不推进；未确认只保存草稿。自评未记住仍是一次已完成的回忆活动，不改变学习覆盖；其关联计划任务不应要求伪造客观 correct。
- 提前复习需明确操作，间隔从实际确认时间计算；遵循已确认的关联计划同步合同。例：11月4日确认模糊，下次11月7日；记住则11月11日。
- 历史查阅继续可看答案；本次复习先作答再揭示答案和原错误。回忆先填写再揭示获准要点、自评后确认。Host 的复习响应按步骤投影，不能只靠前端隐藏。
- 已巩固错题仍可在历史中查看，并可通过现有自由练习路径自主再练，产生新轮次；本轮不修改旧已巩固发生项或暗中重启其周期。若以后要支持明确重新入队，另列增量需求。

以上尚待用户核对，不能标记 closed。该建议取代规格早期未经确认的“模糊保持阶段且次日复习”设想；规格先改为指向本决策，避免两套冲突规则同时充当实施依据。

## Resolution

2026-11-04：用户对正式复习规则表回答“可以”，本票关闭。Discussion 的待确认表格转为正式合同，其历史“尚待”状态已失效。

- 主动回忆首次入队1天后复习；确认后按本次自评安排：未记住1天、模糊3天、记住7天。持续按本次自评安排，不使用错题的三阶段巩固，不把自评转换成客观成绩或掌握率。
- 错题保留既有三阶段推进及失败回退：首次1天后；答对并完成反思确认后，前两阶段分别3天、7天后继续，第三阶段通过标已巩固；答错回待订正，1天后重新开始。已有原始错误与历史记录不改写。
- 提前复习从实际确认时间计算下一次；按已经关闭的计划衔接决策同步同一关联计划项，不重复完成、不自动将下一周期排入正式日程。
- 主动回忆的“未记住”仍表示本次回忆活动已完成，可在回忆内容、自评及本人确认完整时满足对应主动回忆任务条件；错题任务仍须满足原有正确作答和反思条件。两类依据不可用一个 correct 字段混淆，也不撤销已确认学习覆盖。
- 先回忆再揭示要点，先重做再揭示答案；历史查阅保留可见答案。复习读取按阶段返回信息，授权撤销仍生效；保存草稿或查看解析均不推进周期。重复确认不得重复推进或新增历史。
- 已巩固错题可查历史或通过自由练习再练并形成新轮次，本轮不改写旧已巩固发生项、不隐式重新入队。

验收示例：11月4日确认模糊→11月7日；记住→11月11日；未记住→11月5日。重复请求保持同一日期和记录；错题仍按其阶段计算，不受知识点自评影响。需使用可控制时间的公开行为测试验证，当前仅完成决策。
