## Question

复习入队是否只产生到期提醒，排入正式日程必须另经预览确认；或者入队时就联合预览确认排入计划？今日复习提醒和今日计划中的同一复习项如何避免重复呈现、重复完成和容量双算？

现有事实：错题队列与正式计划已分开，加入计划为 append 预览并需再次确认；容量不足会保留待安排项。已批准原型要求入队可选、计划调整预览确认，不等于已确定二者的联合操作方式。

推荐沿用独立提醒与显式排入；讨论逾期、提前复习、计划已排但在复习中心先完成、没有考试日期时的行为。关闭需要用户选择及跨入口同一复习项的身份/完成口径，不实现排程。

## Discussion

2026-11-04 用户选择“独立提醒，确认后排入计划（推荐）”：复习队列独立显示到期提醒，只有预览确认后才排入正式周计划并占用每日容量。此选择已记录，后续不再重复确认。本轮未认领或关闭此票；后续只需澄清跨入口同项的完成、去重和容量处理。

2026-11-04 继续推进，codex 已认领。核对原型 completeReview 只更新复习记录/知识点状态，没有完整表达跨入口同步正式计划任务；当前 Host 则要求先开始复习任务，再取得开始后的新确认依据，不能用早于开始的旧复习记录完成任务。因此这一问题不是原型已批准的细节，也不能只在前端把任务标完成。

建议待用户核对：从任何入口开始已排定的同一次复习时，绑定并开始同一任务；确认按钮明确显示同时完成关联计划项。符合原任务完成条件时，该次确认同步完成关联任务，保留原计划日期和实际完成日期；占用容量不自动腾出或补排。产生的下一次复习仅进入队列，下一次排入正式计划仍预览确认。同一周期不重复排项；新周期不得沿用上一周期的完成依据。错误或缺反思导致条件不足时，只保存本次复习记录并提示计划任务尚未完成。

待确认例子：明天安排的复习，今天从复习中心提前完成，是同步完成原计划项，还是保留原计划项要求到明天另做一次？未收到答复前不关闭本票、不改变实现。

## Resolution

2026-11-04：用户对提前完成同步关联计划项的建议回答“可以”，结合此前“独立提醒，确认后排入计划”选择，关闭本票。上文待确认内容为历史讨论，现按以下合同实施。

- 复习队列独立提醒；只有预览并确认才排入正式计划、占用每日容量。没有考试日期也可使用独立复习队列，不要求先生成倒排计划。
- 同一档案、同一复习对象的同一复习周期，只对应一个有效计划关联。今日列表和复习中心可提供不同入口，但不得重复创建任务、计数或完成依据；下一周期是新的待复习安排，不继承上一周期的完成证据。
- 从任一入口开始已排入计划的复习时，绑定并开始同一计划任务，再记录本次作答或回忆。保留现有“开始后新证据”校验，不允许拿开始前的旧记录直接完成任务。
- 明天计划中的复习今天提前完成时，确认处明确提示“同时完成关联计划项”；满足该任务原有完成条件后，同一次明确确认同步完成该计划项，不要求再回计划页点击一次，也不要求明天重做同一次复习。
- 保留原计划日期与实际完成日期，分别用于安排和实际学习记录。不会自动腾出原容量、补排新任务或悄悄移动其他任务；未来容量调整仍须预览确认。逾期项同理保留原计划日期，不自动复制成今日新任务。
- 答错、缺反思或其他证据不足时，保存真实复习结果并说明计划任务尚未完成，不虚假完成。具体知识点自评推进和跨领域失败恢复分别由后续决策票确定，本票不擅自放宽原任务条件。
- 确认本次复习产生的下一次安排仅进入队列；若要纳入正式日程，再预览确认。未关联计划的自由复习只记录复习结果，不自动新建或完成计划任务。
- 如果在另一入口已经完成同次复习，页面应恢复该次结果；重试同次确认不得重复推进、创建下一周期或再次记完成。多条遗留关联无法唯一判断时明确提示，不静默批量完成。

验证场景：明日复习今日完成且原日程同步；过期任务从复习中心完成；未开始旧证据不可抵扣；两个入口重复确认只记一次；答错/缺项仍未完成；新周期仅提醒不自动占容量；无日期自由复习可用。以上为确定的外部行为，待实施及准确包验收证明。
