## Question

首页继续、路线选课、复习中心和原生课堂怎样定位同一任务、课堂、轮次或复习项？多个未完成任务时默认继续谁？切页与返回后哪些筛选、滚动位置、未提交答案和总结必须恢复？

现有事实：Host 已返回任务 ID 和开始/恢复对象，但总览未使用具体任务导航；课堂/练习草稿可复用，复习草稿只有组件临时状态；页面持久化白名单缺新导航。

推荐提取统一开始/恢复编排、业务状态归档案、展示状态归视图；保留唯一原生输入框与现有 Session，旧导航偏好提供兼容映射。资料、自由练习、模考自报与角色管理作为次级入口仍须可达。

关闭需要：用户核对默认继续和返回路径、状态归属表、旧偏好兼容和窄屏右栏行为；视觉复用已批准原型，不重做整轮原型评审。
