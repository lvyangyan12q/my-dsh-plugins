# 学习与复习改版：实施切片草案

状态：draft-awaiting-review，尚未发布独立实施票。

父规格：[08 学习与复习体验](08-learning-review-experience-spec.md)。本稿采用现有代码增量改造；每片包括必要的持久化、Host、页面及公开行为验证，不按前后端分票。各页面随对应流程落地批准原型的视觉和布局，不留一张最后才制作全部 UI 的工单。

## 发布与执行门槛

- 用户先核对以下粒度、依赖及合并/拆分。批准后按 to-tickets 发布至插件目录下 `.scratch/learning-review/issues/`，一票一文件；本稿不是可领取工单。
- 决策地图的完成合同、导航恢复及交付路径仍开放。批准拆分不自动关闭它们，不表示接受所有推荐细节；相应合同未定稿前，不将受影响票标为可直接执行。
- 完成合同需列出无强制练习、强制练习、部分作答、错题反思等既有条件，以及唯一/歧义依据选择和部分成功重试规则。建议保留既有差异，展示具体缺项；仅重试未成功效果。
- 导航合同需确定多个未完成任务的默认继续顺序、筛选/滚动恢复范围和旧导航映射。建议继续当前档案最近实际操作且可恢复的未完成任务，用户可改选；已删除或失效对象返回列表并说明原因。
- 所有切片沿用已批准的 Host、Native 和页面测试边界；测试用户可见行为及持久结果。发行前固定真实宿主版本和提交，不继承历史通过状态。

## 01：从今日继续同一项真实任务

**Blocked by:** 无实施票；开始前需定稿导航恢复合同。

**What it delivers:** 今日显示真实任务与继续入口，进入任务所属原生课堂或练习；返回、刷新继续同一记录和草稿。先在此窄路径内提取共用开始/恢复操作，再接新页面，不新增另一套课堂服务。

- [ ] 任务身份而非老师或数组下标决定进入对象；重复开始不生成重复课堂、轮次或 Session。
- [ ] 无档案、无计划、无今日任务有可操作空状态；旧资料、自由练习、外部模考、角色管理入口仍可达。
- [ ] 保留完整原生对话、唯一输入框及任务右栏；桌面、窄屏与键盘返回可用。
- [ ] 通过 Host/页面验证恢复、档案隔离和既有草稿；实施前后公共行为保持一致。

## 02：按知识点学习并形成可信覆盖

**Blocked by:** 01。

**What it delivers:** 从科目、章节、知识点路线查看资料并开始/继续学习，明确确认完成后回到路线看到覆盖变化。

- [ ] 稳定知识点身份贯穿任务、课堂和关联练习；讲义遵守已有资料授权，缺资料明确提示。
- [ ] 分母包含大纲全部知识点；分子只计明确完成且可可靠映射的不同知识点，重复学习不膨胀。
- [ ] 旧记录和无法映射的记录保留，不凭标题推断；仅入队、查阅或复习不计已学。
- [ ] 无考试日期可自主学习；阶段、目标与周计划保持可达，预览取消不修改计划。

## 03：错题先重答，再揭示与确认复习

**Blocked by:** 无实施票，可独立验证现有错题入口。

**What it delivers:** 历史查阅继续显示原答案；实际复习先重答、后揭示，再订正反思并确认下一日期，离开后可恢复本次进程。

- [ ] Host 响应与页面均遵守阶段揭示，区分完整历史查阅和复习模式。
- [ ] 保留错题发生项、原评分和解析快照；正确推进三阶段，错误回待订正，重复确认不重复历史。
- [ ] 草稿、已提交作答与揭示状态按档案及复习周期恢复；权限撤销与跨档案请求不泄露资料。
- [ ] 保留历史模式答案可见的旧测试，新增复习模式揭示前不返回答案的公开接口测试。

## 04：知识点主动回忆完整闭环

**Blocked by:** 02。

**What it delivers:** 学习者手动确认将知识点加入复习中心，先回忆、揭示获准要点、自评并确认，得到下一日期和可恢复历史。

- [ ] 初次 1 天；未记住/模糊/记住分别从实际确认起计算 1/3/7 天；不使用错题巩固阶段。
- [ ] 到期、逾期、未来、科目/知识点筛选和空队列可用；未记住仍可完成本次回忆活动。
- [ ] 自评不计客观正确率、不新增或撤销已学；同周期重试不重复入队或推进。
- [ ] 无要点或授权失效明确反馈；返回、刷新和重启恢复草稿与本次周期。

## 05：一次收尾确认与失败后恢复

**Blocked by:** 01、04；开始前需定稿完成合同。

**What it delivers:** 课堂任务面板集中展示依据、总结、缺项和可选复习，学习者确认后收到准确回执；发生部分成功时继续完成剩余步骤。

- [ ] 仅自动关联唯一且匹配的真实依据；歧义候选用标题/时间供选择，不要求手填 ID。
- [ ] 保存草稿、Stop 或模型建议不完成任务；保留各任务真实练习/反思条件，未答规则不被悄悄更改。
- [ ] 完成已保存但入队失败时明确显示两者结果；重试不重复完成、记分或入队，刷新可恢复未完成效果。
- [ ] 可不加入复习，也可稍后加入；首次日期可见，下一项和返回今日均可用。

## 06：复习预览排程与跨入口提前完成

**Blocked by:** 03、05（04 经 05 间接依赖）。

**What it delivers:** 复习中心统一展示两类复习，预览确认后排入正式周计划；今日与复习中心恢复同一周期，提前完成同步更新关联任务。

- [ ] 入队不占计划容量；确认预览才写入日程，版本过期拒绝，溢出可见，取消无影响。
- [ ] 同一对象/周期不重复排程；开始绑定同一计划项，只认开始后的本次凭据。
- [ ] 完成前显示将同步完成的计划项；保留计划日期和实际日期，次日不重复要求完成。
- [ ] 错答或缺反思保留真实尝试但不完成关联错题任务；未记住的已确认回忆按其独立活动条件处理。
- [ ] 下一周期只回队列，不自动补容量或重排；重试、跨页、重启保持一致。

## 07：从真实学习进度调整未来安排

**Blocked by:** 06（路线及两类复习均为间接依赖）。

**What it delivers:** 学习进度分别展示覆盖、客观练习成绩与复习完成；学习者从薄弱项追溯记录，再预览并确认未来计划调整。

- [ ] 显示真实分母、同题多轮/未答量及外部模考自报的区别；主观回忆不混入正确率。
- [ ] 弱项推荐有真实历史依据，复习失败不抹去已学；无数据不造百分比。
- [ ] 未来未开始项可调整，已完成和进行中项受保护；容量不足、取消和版本冲突反馈明确。
- [ ] 四个主入口往返保持同一任务上下文，筛选与返回状态遵循定稿导航合同。

## 08：准确发行包的独立闭环与恢复交付

**Blocked by:** 07；发布前需定稿交付路径。

**What it delivers:** 在临时独立 home 安装准确发行包，完成完整学习和两类复习路径，并验证重启、原位升级/重装及共存边界，形成可复核交付记录。

- [ ] 固定源码、宿主实际提交/版本、包哈希；构建用物理隔离依赖，安装文件与准确包逐文件一致。
- [ ] 无工作台环境真实走目标→预览确认→学习→评分/反思→完成→两类复习→进度调整；不同档案、重复确认、恢复与冲突均有证据。
- [ ] 验证原生私有 Skill、问题卡片、拒绝/允许一次审批、Stop、唯一输入框及桌面/窄屏；不把静态原型或模拟响应当实装。
- [ ] 共存只验证独立入口、工具/会话边界，不引入工作台依赖；原始资料、快照、Session/cwd、其他插件与新增学习记录受保护。
- [ ] 记录未测范围、回退材料和启动方式；不启动用户日常 3080，不公开发布、不推送。正式安装若另行要求，先完成保护与现场核对。
- [ ] 浏览器 DevTools 验收；原生鼠标/窗口另行确认，人工 IME 与未测平台不记通过。
