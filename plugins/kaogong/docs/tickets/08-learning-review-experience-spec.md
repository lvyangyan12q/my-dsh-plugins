## Problem Statement

学习者目前能使用计划、课堂、练习和错题功能，但必须在多个页面间管理任务总结、作答轮次、角色与完成依据。首页不能直接继续具体任务；计划页同时暴露设置、全程任务和技术状态；课堂结束后还要手动关联记录、返回计划确认，学习主线容易中断。

第一版交互原型只回答了一次任务如何完成，仍缺少全程备考、按章节系统学习以及覆盖已学知识点的复习体系。学习者需要知道现在处于哪个阶段、哪些内容学过、今天为什么学这些、何时复习，以及复习结果如何影响后续安排。

## Solution

以用户已确认的第二版 Open Design 原型为视觉和交互基准，形成“今日、学习路线、复习中心、学习进度”四个主要入口，资料、备考档案和设置作为次级入口。课堂与学习收尾作为具体任务流程，继续使用完整 Harness 原生对话和右侧学习面板。

全程路线产生周安排与今日任务；点击具体任务直接学习。任务记录自动关联，学习者补充总结后明确确认完成，并可在同一处确认加入复习安排。复习覆盖知识点主动回忆、错题重做及薄弱点专项，结果回到进度，再通过差异预览和本人确认调整未来计划。

本规格是现有独立考公规格的增量：替代原六页导航及相关操作布局，增加知识点复习和学习路线；原有数据归属、真实评分、权限、原生课堂和恢复要求继续有效。历史已关闭工单不代表本轮已实现。

## User Stories

1. As a 备考学习者, I want 打开考公即看到今日学习, so that 我知道当前最值得做的事情。
2. As a 备考学习者, I want 首页显示上次具体任务与继续按钮, so that 我不用重新寻找老师和课堂。
3. As a 备考学习者, I want 每项今日任务标明阶段和计划来源, so that 我理解安排的理由。
4. As a 备考学习者, I want 直接开始或继续今日任一任务, so that 我不必先进入计划管理页。
5. As a 备考学习者, I want 清楚看到到期和逾期复习, so that 旧知识不会被新任务掩盖。
6. As a 初次使用者, I want 无档案、无计划或无资料时得到对应行动入口, so that 我能逐步开始备考。
7. As a 考试日期未定的学习者, I want 保存目标并自主学习, so that 系统不会强迫我填写虚构考试日期。
8. As a 备考学习者, I want 查看考试目标及基础、强化、冲刺阶段, so that 我能理解整个备考路线。
9. As a 备考学习者, I want 查看各科的章节与知识点层级, so that 我能系统学习而不是只处理零散任务。
10. As a 备考学习者, I want 区分未学、在学、已学与待复习状态, so that 我能选择下一步内容。
11. As a 备考学习者, I want 从当前章节直接继续关联课堂, so that 我无需重复创建课堂。
12. As a 备考学习者, I want 自主选择其他科目和知识点, so that 我可以临时解决自己的疑问。
13. As a 备考学习者, I want 查看由学习路线产生的周安排, so that 我能判断近期负担。
14. As a 备考学习者, I want 按需打开目标和计划调整, so that 日常学习不被大段设置表单干扰。
15. As a 备考学习者, I want 看到未排入和逾期任务, so that 容量不足不会让任务悄悄消失。
16. As a 课堂学习者, I want 进入完整原生对话并看到当前任务面板, so that 我可以同时交流与查看学习目标。
17. As a 课堂学习者, I want 保留模型、轨迹、提问、审批、Stop 和唯一输入框, so that 原生交互不会被插件替代或遮挡。
18. As a 课堂学习者, I want 系统按任务自动选择任课老师或辅导员, so that 我不用在每个页面手动切换角色。
19. As a 课堂学习者, I want 面板突出当前目标、讲义、练习和下一步, so that 我能专注正在进行的任务。
20. As a 课堂学习者, I want 切页、返回或暂时离开后继续同一任务, so that 会话、作答和草稿不会丢失。
21. As a 练习者, I want 任务发起的练习自动与任务关联, so that 我不用输入轮次编号或手动拼接依据。
22. As a 练习者, I want 提交后查看真实成绩、未答题和错题, so that 我能准确判断本轮表现。
23. As a 练习者, I want 在收尾处补充总结和所需错因, so that 我不必到多页重复填写。
24. As a 学习者, I want 区分保存草稿与确认完成, so that 未完成的学习不会被误记为完成。
25. As a 学习者, I want 缺少完成条件时看到具体缺项和直接入口, so that 我知道怎样完成任务。
26. As a 学习者, I want 一次明确确认后看到完成回执, so that 我知道学习记录确实已保存。
27. As a 学习者, I want 完成时看见并选择是否加入复习及首次日期, so that 我明确控制后续安排。
28. As a 学习者, I want 完成后继续下一项或返回今日, so that 学习过程连贯。
29. As a 复习者, I want 在一个中心看到到期、逾期和后续复习, so that 我能统筹巩固任务。
30. As a 复习者, I want 复习已学知识点而不仅是错题, so that 我能主动检查遗忘。
31. As a 复习者, I want 按科目、知识点筛选和自主发起复习, so that 我可以集中巩固薄弱内容。
32. As a 复习者, I want 看到每项推荐理由和复习间隔, so that 我理解系统为何安排它。
33. As a 知识点复习者, I want 先回忆再查看要点, so that 我不会把看懂误当作记住。
34. As a 知识点复习者, I want 用未记住、模糊、记住记录自评, so that 我能如实表达回忆体验。
35. As a 知识点复习者, I want 自评与客观作答成绩分开, so that 系统不会虚构掌握率。
36. As a 错题复习者, I want 先重新作答再查看答案、解析和原错误, so that 我能检验是否真正订正。
37. As a 错题复习者, I want 保存订正和反思后确认复习, so that 新的作答有完整记录。
38. As a 错题复习者, I want 后来答对仍能看到原错题历史, so that 反复出错的线索不会被覆盖。
39. As a 复习者, I want 确认后看到下一次复习日期并可进入下一项, so that 我知道后续如何安排。
40. As a 复习者, I want 队列清空后得到明确反馈和自主复习入口, so that 我不会面对空白页面。
41. As a 备考学习者, I want 分别查看学习覆盖、练习正确率与复习完成, so that 我能准确理解各类进度。
42. As a 备考学习者, I want 查看反复出错知识点及学习、复习记录, so that 我能找到需要调整的内容。
43. As a 备考学习者, I want 从薄弱项预览未来计划变化, so that 我能有依据地重新安排学习。
44. As a 备考学习者, I want 计划确认前看到差异并可取消, so that 建议不会未经我同意就生效。
45. As a 备考学习者, I want 调整保护已完成和进行中任务, so that 已有成果与会话不会被重排破坏。
46. As a 多档案学习者, I want 每份档案的路线、草稿、复习和记录彼此隔离, so that 我不会混入其他备考上下文。
47. As a 窄屏或键盘用户, I want 导航、任务面板、表单和反馈仍可操作, so that 窗口尺寸与输入方式不会阻断学习。
48. As a 学习者, I want 刷新、重启和准确发行包重装后恢复记录, so that 原型中的顺畅流程在日常使用中也可靠。

## Implementation Decisions

- **已确认的学习口径**：使用现有科目→章节→知识点大纲，讲义挂接到稳定知识点。覆盖分母为完整大纲中的知识点（包括暂缺资料者），分子为本人明确确认完成学习的不同知识点；同一点重复学习只计一次。仅入队、浏览或复习不能变成已学，复习失败不撤销已学；待复习与已学可以并存。不能可靠映射的历史记录保留，不凭标题猜测归属。
- **已确认的队列与日程边界**：复习队列独立提醒，只有预览并确认后才进入正式周计划并占用容量。从复习中心提前开始已有计划项时，绑定并开始同一任务；完成条件满足后，一次明确确认同步完成关联计划项，保留计划日期与实际完成日期。只认任务开始后产生的本次复习证据，同一对象的同一周期不重复入队或排程。未满足条件时保留真实尝试但不完成计划。提前完成不自动补满容量、不重排其他任务，下一次复习只进入提醒队列。
- **决策与实施状态**：路线口径、队列与日程、复习推进规则已定稿。完成条件的精确对照、跨领域部分成功恢复、多个任务默认继续及返回现场规则仍在决策地图中开放。下文明确标为“待定”的内容是推荐方案；不可当作用户已批准合同。规格的 ready-for-agent 是 triage 标签，执行仍受 pending-decisions 约束。实施票拆分先评审，再发布。

- **当前实现核对后的实施方式**：采用增量改造，不重写整插件。既有档案/权限、原生接入、真实评分、计划调度与错题历史继续复用；四个页面和课堂任务面板重组或重做；新增知识点身份关联、学习进度投影与主动回忆领域。既有分类树不是完整课程进度模型，不能仅增加一层导航宣称完成。
- **已存在的能力**：Host 已有任务开始并恢复课堂/轮次的入口；课堂确认已能回写计划；错题已有 1/3/7 天规则和历史。实现需先提取共用操作编排接到新页面，而非重复造同名服务。
- **必须改变的现有行为**：历史错题查阅目前直接返回和展示答案；新复习模式必须与历史模式区分，并在 Host 返回层按阶段揭示。旧复习记录保持兼容，不将知识点自评伪装成旧模型的客观答题结果。
- **持久化补齐**：现有课堂/练习草稿可复用，复习草稿与四页导航持久化需新增。跨领域的完成、计划回写和复习入队采用可重试的明确编排，不能假定一个前端按钮意味着已有跨领域事务。

- **原型与产品边界**：用户认可第二版信息架构、视觉方向和流程；原型仅提供交互决策。演示日期、固定 8/10、三项任务、模拟聊天与刷新重置不进入正式业务。
- **术语**：界面沿用备考档案、科目、章节、知识点、学习任务、课堂、练习轮次、错题发生项、复习记录。共享词汇中的实例/视图归属继续有效，但不引入工作台依赖；“已学”仅表示学习完成，“待复习”是可叠加的复习状态，不等于撤销学习完成。
- **页面结构**：四个主要入口；周计划与目标设置整合在学习路线，练习由今日、路线或次级自由练习入口进入。资料、档案管理、角色设置和技术详情按需打开，既有功能保持可达。
- **视觉布局**：暖白、深墨绿、中文排版和清晰主次操作遵循原型；同时适配宿主主题、可读对比度与焦点样式。桌面保留原生对话主区域和约 320px 学习面板；窄屏使用宿主公开能力提供可收起面板，关闭后焦点回到触发控件。
- **今日及继续导航**：根据真实稳定任务身份恢复所属课堂、轮次和草稿。无进行中任务时推荐可开始项，不能将“继续”实现为仅打开默认老师。任务、章节、复习三个入口指向同一所属记录，切换页面不创建重复任务或会话。
- **学习路线**：复用现有科目分类与知识点身份建立章节展示和学习状态投影；章节覆盖以该章节完整大纲知识点为分母（包含缺资料项），已确认学习的知识点去重计入分子，不以资料数量或固定演示数量推断进度。未知资料、空章节和无法映射历史记录明确显示，不伪造可学内容；旧记录保留且不靠显示名称猜测归属。
- **计划**：沿用目标、每日模块容量、科目权重和阶段调度。预览具有版本与具体差异，确认时重新校验。未来未开始任务可调整；已完成、进行中及既有逾期保护规则保持。溢出项显示待安排。无日期仍可自主学习，不生成虚构倒计时。
- **原生课堂与角色**：以公开 Scope、preset、Session、侧栏与右栏能力集成；保留运行时身份与私有 Skill 隔离。按任务职责恢复任课老师、辅导员或班主任绑定；角色选择降级为按需操作。只保留原生输入框，不修改 Harness 源码或复制其聊天界面。
- **自动关联与收尾（精确合同待定）**：推荐由 Host 校验任务、课堂与轮次归属，使用任务开始后匹配的真实依据。只有唯一且正确的关联才自动采用；歧义时呈现带标题和时间的候选供选择，不能让用户填技术 ID，也不能擅自采用“最新一轮”。完成必须符合该任务实际的总结、练习和反思要求；非强制练习的学习任务仍可直接总结完成。
- **一次明确确认**：将依据展示、缺项提示和最终动作集中在任务收尾。草稿保存不完成任务；开启或停止原生对话不完成任务；AI 建议不直接生效。重复点击、重试或刷新不能重复记分、完成或入队。多步持久化必须能恢复并显示真实部分成功状态，失败不能显示全部完成。操作身份、重试顺序以及各类任务的完成条件对照须在完成合同决策中定稿，不能借 UI 改版统一或放宽原有不同条件。
- **加入复习**：收尾明确显示是否加入、复习对象和首次日期；学习者可选择后与完成一起确认，也可稍后单独加入。知识点可独立于错题入队。复习队列与正式日程是不同概念：入队不静默重排正式计划，将复习纳入正式日程仍需差异预览确认。
- **复习模型**：复用既有错题发生项与历史记录，增量支持知识点主动回忆。新记录保存所属档案、稳定知识点/来源身份、复习类型、本次依据、确认时间与下一日期；主动回忆保存周期及自评，错题保留巩固阶段，自评与客观判分分别存储。具体存储和接口命名在实施时按现有模块确定，不创建第二套练习评分或错题历史。
- **主动回忆**：先输入回忆，再主动揭示已授权要点，然后选择未记住/模糊/记住；确认前不更新复习历史和进度。自评不得换算成客观掌握率。无可用要点时说明原因，并提供查看获准资料或返回入口。
- **错题复习**：新增与历史查阅分离的复习模式，先答题、后揭示答案与原错误，再保存订正反思并明确确认；Host 返回层也必须按阶段隐藏答案。保留现有历史查阅显示完整答案的行为。错误仍进入待订正，不能推进巩固阶段；历史原题、原作答、原评分与解析快照保持。通过阶段仅称已巩固，不宣称长期掌握。
- **间隔规则**：知识点主动回忆初次确认入队后 1 天到期，之后按本次自评安排未记住 1 天、模糊 3 天、记住 7 天；不套用错题的三阶段模型。实际回忆、自评并确认可以完成一次回忆活动，“未记住”不等于未复习，也不会新增已学或客观正确率。错题保留初次 1 天、答对后第 1 阶段 3 天、第 2 阶段 7 天、第 3 阶段已巩固；答错回到待订正并在 1 天后再复习。间隔从实际确认时间计算，提前复习明确提示，重复确认不再次推进。已巩固错题保留历史，自由练习创建新轮次而非隐式重开旧复习。日期显示沿用既有学习日期口径，覆盖跨日与时区边界；不宣称算法科学最优。
- **统计与反馈**：学习覆盖、已提交练习准确率、复习到期和确认完成分别计算；沿用累计题量、实际作答量、未答量与去重题数区分。外部模考自报保持单列。弱项基于真实历史，说明推荐理由；无数据不显示伪造百分比。
- **草稿与恢复**：正式实现持久保存按档案及任务/轮次/复习项隔离的草稿，切页与返回可恢复；提交成功后仅清理相应草稿。默认继续对象、筛选/滚动恢复范围及旧偏好映射仍待导航恢复决策定稿，推荐业务记录按档案归属、展示状态按视图归属。刷新重置只属于原型。并发版本冲突、断网、取消和未知发送状态有可恢复反馈，不自动重复发送或吞掉用户输入。
- **边界与数据保护**：沿用鉴权、模型真实 Session 归属和资料授权/撤销；页面不能指定其他档案写入，模型不能代替页面确认。只增量保存学习路线与知识点复习元数据；不自动接管旧全局记录，不改原题、答案、评分快照、材料证明、已有 Session/cwd。回退恢复本轮插件与配置，不整库覆盖新增记录。

## Testing Decisions

- **沿用已确认边界**：用户在本会话已确认 Host HTTP/模型工具（鉴权、档案隔离、真实判分）、原生侧栏/Session/右栏、页面确认操作及准确发行包无 Worktable 端到端验收。本轮继续使用这些相同边界，新增学习路线与主动回忆场景，不新增需要用户重新确认的底层测试接口。
- **最高层主验收入口**：准确发行包安装后的学习者完整路径。测试可见文本、可执行操作及最终持久记录，不依赖组件内部状态、私有函数、CSS 类名或原型的固定数量。下层 Host 测试只补足权限、并发和恢复等高层难覆盖的边界。
- **既有先例**：沿用独立 Host/client、原生导航、计划任务与计划页面、任务续学、练习轮次与统计、错题复习页面、课堂、草稿恢复及发行产物门禁的测试模式；保留已有题目快照、幂等判分和二档案保护用例。新知识点复习通过同一 Host/页面边界测试，不为实现细节新增专门测试后门。
- **主流程**：设置真实目标并预览确认计划→路线选择知识点→今日继续同一任务→原生课堂→真实练习与反思（如要求）→明确完成并确认加入复习→复习中心主动回忆→揭示及自评→确认下一日期→进度记录→预览并确认未来计划调整。对照未确认前后证明只有明确操作改变正式状态。
- **路线与导航**：科目、章节、知识点状态正确；学习完成与待复习可并存；自主学习可用；从各入口恢复同一任务与会话；无日期、无资料、空知识点、自主筛选无结果及无今日任务均有可用入口。
- **复习矩阵**：到期、逾期、未来与提前复习；三种自评；三阶段推进、回退和下一日期；错题答对/答错、缺反思、揭示前不泄露答案；重复确认不追加历史；过去错误不被后续答对覆盖；队列清空后仍可自主复习。
- **完成与统计**：不要求练习的任务、要求练习的任务、缺总结/错因、错误归属轮次、重复提交、同题多轮、未答题以及外部自报。自动关联不越档案、不采用不匹配轮次；不存在“打开页面即完成”。覆盖实际数据并确认原型固定 8/10 没有进入评分实现。
- **恢复与冲突**：切页、返回、关闭重开、刷新、Host 重启、准确包重装恢复任务/会话/cwd/草稿/复习；过期计划预览拒绝；断网或部分保存后可恢复；并发确认与重复点击不重复完成、记分、入队或发送。
- **原生与隔离**：私有 Skill、问题卡片、拒绝和允许一次审批、Stop、唯一原生输入框；二档案工具与会话边界；资料权限撤销；无 Worktable 环境完整闭环。与工作台共存只验证入口和边界，不把其作为依赖。
- **视觉与可访问性**：桌面 1440px、窄屏及低高度窗口；键盘顺序、焦点恢复、表单标签、禁用原因、就地错误和异步反馈。界面验证通过浏览器 DevTools；Windows 原生窗口/系统鼠标另行确认。未执行的人工 IME 和平台不记为通过。
- **发行门禁**：实施时固定实际 Harness 提交、版本、插件源码与最终包哈希；重新运行声明、构建、回归、独立安装与逐文件一致性门禁。历史 rc.3 或 alpha.2 验收不替代本轮。实施完成需要新的准确发行包证据，不以原型、规格、提交或标签代替。
