# 任务驱动课堂：落地清单

这是规格配套的实现导航，不是已认领实施工单。范围与验收以 [规格](task-centered-learning-spec.md) 为准。

| 切片 | 具体改造 | 阻塞与通过条件 |
| --- | --- | --- |
| A：绑定与内嵌能力 | 核对公开原生对话挂载、指定会话、输入及运行生命周期；设计持久任务会话引用和教学发送幂等键 | 先实测课堂内发送/流式/Stop/提问/审批/恢复；能力缺口必须明确，不用跳转代替 |
| B：任务直达课堂 | 复用计划 start 返回的 lesson/round/review 引用，去掉重复目标表单；课堂导航恢复最近有效任务；无任务直达今日 | Host 并发 start 幂等；已有任务一次点击、零配置；过期请求不会覆盖新任务 |
| C：固定角色＋内嵌答疑 | 去掉角色配置 UI；班主任按档案、老师按任务绑定；拆分准备/提交/导航，显式动作一次提交；只主动查看完整对话才跳出 | 依赖 A；真实运行不跳页、不会重复消息或错会话发送；停止/审批可达 |
| D：课堂内练习与收尾 | 复用题目、判分和复习组件，在当前课堂内切学习阶段；自动关联轮次；总结和明确确认只在一个位置 | 依赖 B/C；不输入轮次 ID；正式评分不依赖客户端正确字段；只确认一次完成 |
| E：导航与复习直达 | 资料库、自由练习同级展示，取消“资料与工具”；复习中心直接开始已有复习项；自由练习不误关联任务 | 保留档案隔离、历史入口和未保存草稿；学习主动作不重复 |
| F：内容与交付门禁 | 校正或下架错误示例；完成多视图、窄屏、冷启动、准确包重装和真实学习路径 | 依赖全部切片；未通过项不写“已完成”；正式发布与本地测试包分开 |

## 现有改造入口

- [学习总览与导航](../src/sdk-classroom.tsx)：角色配置、教学准备及打开会话的现有编排。
- [今日与计划任务](../src/study-plan-panel.tsx)：复用任务开始与课堂/轮次恢复，不再结束于强制打开老师会话。
- [原生导航适配](../src/study-native-navigation.ts)：目前先打开原生会话再挂学习侧栏，改为按需的“查看完整对话”，不再成为教学必经路。
- [课堂](../src/lesson-panel.tsx)：移除主流程新建课堂/重填目标；承接当前任务、讲义、检测、练习及统一收尾。
- [会话与教学任务客户端合同](../src/study-client-contracts.ts)：现有 ensure/open/prepareOwned/submit/recover 需明确任务归属与幂等；优先扩展现有适配边界。
- [客户端集成](../src/client.tsx)：保留档案/视图隔离，在插件壳中挂载公开原生会话能力。

## 已核对的公开内嵌路线（静态证据，尚待真实探针）

- `ctx.sessions.retain(sessionId, { source, signal })` 返回会话引用；等待 `ready`，用公开 `SessionProvider` 提供作用域，退出释放引用。保留会话不改变导航，也不拥有后台 Agent 生命周期。
- 在插件 session-scoped Slot 中复用 `conversation.content` 的 embedded Factory，并将 views 接到固定 chat 的 `conversation.session`。完整 content 已有 composer 和 input dock，不另造第二个输入框。
- 指定会话内的 `ctx.conversation.send/cancel` 或公开 SessionFace 承担发送与停止；复用原生流式和审批。停止当前 turn 后原生 Queue 可能继续按 FIFO 执行，不能把 Stop 宣称为清空全部任务。
- 参考[公开会话 retain 合同](../../../../deepseek-harness/packages/api/session-controller/src/client/contract/sessions.ts)和[现有子代理内嵌先例](../../../../deepseek-harness/packages/client/ui-subagent/src/client/sidebar-chat/index.tsx)。这些为本机研究指针，不是插件运行时私有依赖，不可直接导入其源码。
- 普通标准会话在考公主面板嵌入仍须实测：审批/问题浮层、Stop 与排队、刷新 retain/release、双视图输入焦点和草稿归属。子代理侧栏可用不等于考公课堂已通过。
- 当前教学提交已有持久 requestId 和 unknown 状态保护；保留 unknown 不自动重发的安全行为，不能为了简化交互去掉。

## 证据矩阵

| 行为 | 最低验证边界 |
| --- | --- |
| 一次点击进入正确任务，无重复表单 | 页面集成＋准确安装包浏览器 |
| 同任务不会重复课堂/教学发送 | Host 存储集成，并发与失败重试 |
| 真正留在课堂答疑 | 公开 API 探针＋真实 Agent 流式/工具/审批/Stop |
| 不串档案、不串任务 | 多视图、切换期间延迟响应、真实 sessionId 核对 |
| 真实评分和一次完成 | 练习/计划/课堂集成；假聊天成功不算证据 |
| 重开后仍可用 | 冷启动、准确包重装、草稿及会话恢复 |
| 用户能专注学习 | 桌面/窄屏实测，点击计数、键盘和中文输入 |
