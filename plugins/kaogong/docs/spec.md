# 考公独立学习系统规格
状态：closed（2026-10-28）；本轮规格，替代以工作台接入成功作为考公产品完成的判定。最终发行、真实闭环、保护清单与限制见[最终验收](evidence/07-final-acceptance.md)。

## 目标与范围
在不安装、不启用工作台的官方 DSH 0.2.1-rc.3 中，独立完成“目标设置→计划预览确认→今日学习→练习提交判分→错因反思→复习→进度与计划调整”，关闭、刷新、重启后能继续。
复用现有题库、资料证明、练习快照、评分、课堂与持久化；本轮不重建通用应用平台、不修改Harness源码。新独立版本拟为0.3.0-rc.3.1，已有rc.3.7只是适配基线。

## 页面与使用流程
- 原生侧栏提供明确的“考公学习”，默认学习总览，不进入空课堂或通用实例管理。
- 六个主要页面：学习总览、学习计划、练习训练、错题与复习、学习进度、资料库。
- 总览显示考试目标、今日任务、待复习队列、计划完成、练习正确率、薄弱点、继续上次学习。
- 计划可设置考试日期/每日模块数/科目权重；提供按日/周及全程日程、预览、确认、调整和历史版本。
- 多实例在用户界面称备考档案；默认继续上次档案，管理放设置。首次设置向导确认后创建，不在render时自动建档。
- 未设置日期不显示默认倒计时；预计日期明确标注。日期未知仍可阅读/自由练习、保存档案草稿，不伪造倒排计划。
- 班主任负责计划/进度；任课老师负责科目教学；辅导员负责讲评/错因/复习。保留kaogong-teach私有Skill身份和既有绑定，不新增全局创作模式。
- 从任务进入完整DSH原生对话，右侧原生学习面板展示目标、讲义、练习和反思。保留标题栏、模型、轨迹、提问、审批和Stop；不复制聊天框。切换角色与回到总览不丢各自内容。

## 计划与任务
沿用基础/强化/冲刺调度、每日模块数与科目权重。每项任务使用稳定ID，不用数组位置作为持久关联。新计划和调整先生成草稿及差异，确认后生效。
批量重排仅处理未来未开始任务；已完成和进行中任务默认保持。未完成不自动消失或完成；延期/追加要明确。每日容量不足显示未排入任务，不静默超排。版本、完成依据与更正历史持久保存。
完成条件：学习保存总结并由学习者确认；练习有匹配的已提交轮次及所需错因反思，再明确确认；错题复习有重新作答/订正与本次确认；外部模考用户自报、单列，不计入系统判分。
课堂是否要求课后练习须显示，不把所有学习任务隐含变成刷10题。Native结束/空闲/Stop不代表完成。

## 练习、错题与复习
保留Host发题快照和真实评分、提交前隐藏答案、同轮相同提交幂等、冲突拒绝。未交卷轮次可继续，已有轮次不被后来题库更新覆盖。
错题本可筛选科目/考点/错因/日期/状态，展示原题、原作答、答案解析、来源、笔记及历次复习，不因后来答对覆盖过去错误。
用户确认加入复习队列后按1/3/7天递进；复习错误回待订正，短间隔重新开始。通过三阶段标已巩固，不宣称长期掌握。队列按已确认规则更新；纳入或调整正式日程仍预览确认。
跨轮次薄弱点/错因归纳可持续查看，不依赖刚交一轮练习。

## 统计
成绩从已提交轮次汇总，错题本负责归纳和复习。分别表达累计提交题量、实际作答量、未答量、去重题数；同轮重交不重计，重复题的不同轮次不丢失。
本轮准确率沿用完整轮次分母，未答单列；累计采用相同口径明确分母。任务完成率与题目准确率分开，外部自报与系统判分分开。未配置/无数据用明确空状态。
测试至少包括相同10题两轮、3对2错5未答、跨轮次汇总和幂等重提。

## 独立架构
考公自身拥有备考档案/视图上下文、资料与只读授权、学习业务、原生角色绑定及教学任务回执。移除核心Host/client/types/发行依赖对dsh-worktable/sdk及worktable*的必需引用；不保留隐形后台依赖。
浏览器使用Host登记上下文；模型工具按真实Agent.session.id解析所属档案，不允许模型指定其他档案。保留资料来源、权限撤销、私有资料隔离及原题校验。
增加版本化任务/复习/计划元数据，尽量保持已有练习/题库/知识/课堂格式，通过增量关联避免批量重写原题与成绩。
通过rc.3公开侧栏main插槽、原生sidebarRight及Session控制器接入。保留标准preset＋私有Persona/Skill、目录完整性和源码/编译Scope身份检查；不猜路径或削弱guard。
手动计划、阅读、练习、评分、反思、统计在模型不可用时仍可运行。AI只能建议及读取获准数据；计划变更和完成建议由用户页面确认，不改既有成绩/答案。

## 数据与迁移
保留本轮已创建的档案、课堂、成绩、草稿、资料接入回执、共享关系和老师绑定。旧全局计划/错题/会话原址保留，不自动接管。
原题、答案、PDF、图像和MinerU成果搬迁遵循migration.md：先复制/证明/验证，再切换、归档或清理。运行home凭据和Native会话不搬入Git。
真实资料仅本地；代码/规格/工单/脚本/脱敏结果进Git。回退仅插件与配置，不整库覆盖新增学习记录；新域保留，降级不能显示也不删除。

## 完成门槛
准确发行包在无工作台环境完整安装；真实完成计划→学习→练习→反思→复习→进度→确认改计划，并验证Native私有Skill、问题、审批拒绝/允许一次、Stop。
验证两个档案、来源授权/撤销、重复评分保护、未来计划调整、关闭重开/刷新/Host重启/准确包卸载重装。人工IME或宿主限制单列真实证据，不从自动输入推断。
正式切换前核对当前在用会话/草稿，备份并展示具体影响，保护原材料与用户改动；验证后注册正式profile、按授权推送并关闭自建验收实例。旧Worktable适配已通过的范围不是本轮独立闭环完成证明。
