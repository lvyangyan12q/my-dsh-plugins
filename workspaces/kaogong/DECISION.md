# 决定：考公面板的交互方向

日期：2026-11-07

## 结论

- **信息架构不动**：保留现状（N）的六页签 —— 总览 / 计划 / 练习 / 错题 / 进度 / 资料库。
- **要动的是每页内部的点击**：按下面五条规矩逐页收敛。
- **计划页的容量改行内 − / +，点完即时生效**：不要“调整容量 → 选 2/3/4 → 保存”这套弹层。
  这也否掉了“计划页只读、所有调整都在对话里说”的做法 —— 改一个数字不该打一句话。
- 参考原型：`kaogong-interaction-prototype.html`（四方案对照，N 为基线，含诊断与可点区域审计）。
- 逐页收敛版：`kaogong-pages-prototype.html`（同一结论的可点击样本，备用）。

## 五条规矩

1. 页签只负责“去哪”。页面里不再出现“查看学习计划 / 打开知识库”这类导航链接。
2. 每页一个主按钮。列表用手风琴，一次只展开一行，所以主按钮同时最多一个。
3. 行 = 展开或打开；按钮 = 执行。两者不混。
4. 删掉流程噪音：刷新由数据变化触发；确认只在最后一步出现一次。
5. 空态给一个动作，不写“请在对话里说……”。

## 每页一条主线

| 页面 | 唯一的主动作 | 拿掉 |
| --- | --- | --- |
| 总览 | 展开那行后「开始」 | 刷新、查看学习计划、自由练习、错题与复习、练习历史、每模块两个按钮 |
| 计划 | 行内 − / + 直接改每天件数，点完即时重排 | 科目/类型/标题三个字段、两个“预览”、二选一 chip + 保存按钮 |
| 练习 | 「开始练习 · N 题」 | 练习历史、专项/错题两个模式 |
| 错题 | 展开考点后「开始复盘」 | 刷新、科目筛选、搜索、常驻的复盘/写错因、确认完成 |
| 进度 | 没有按钮（只读） | 刷新、查看模块统计、导出（收进「⋯」） |
| 资料库 | 搜索框 + 点行开阅读器 | 刷新、导入、新建笔记、重复的类型 chip |

一屏可点：总览 6 / 计划 5 / 练习 7 / 错题 6 / 进度 4 / 资料库 8。
